Getting started

This page shows you how to get a small GTK 4 sample application running from scratch.

Requirements

  • An opam switch with OCaml 4.14.2 or later installed
  • Operating System: Linux or macOS (Windows is not supported at this time; ocgtk remains untested on the BSDs)

Install

System dependencies

opam can install system dependencies itself on some platforms, but it's usually a good idea to do this yourself. On most platforms, this is the GTK 4 development package.

For example, on Debian/Ubuntu, Fedora and macOS systems:

sudo apt-get install libgtk-4-dev     # Debian, Ubuntu
sudo dnf install gtk4-devel           # Fedora
brew install gtk4                     # macOS (Homebrew)

Installing ocgtk

ocgtk is one of a group of related packages, one per library, e.g. ocgtk for GTK 4, ocgdk for GDK and ocpango for Pango. There are also corresponding conf-* packages, which ensure that the C dependencies (from the previous step) are installed (see Libraries and namespaces).

From opam

opam install ocgtk

From the ocgtk repository

You will need to pin the repository's packages first, then install ocgtk:

git clone https://github.com/chris-armstrong/ocgtk.git
cd ocgtk
for p in conf-*/; do opam pin add -n -y "${p%/}" "./$p"; done
opam pin add -n -y .
opam install ocgtk

Create a project

Create a directory with three files:

counter/
  dune-project
  dune
  counter.ml

dune-project:

(lang dune 3.0)

dune:

(executable
 (name counter)
 (libraries ocgtk))

counter.ml:

open Ocgtk

let activate app =
  (* Create an ApplicationWindow and set its title and size *)
  let window = Application_window.new_ app in
  window#set_title (Some "Counter");
  window#set_default_size 300 200;

  (* Set up a counter, a label and a button *)
  let count = ref 0 in
  let label = Label.new_ (Some "Clicked 0 times") in
  let button = Button.new_with_label "Click me" in

  (* `ignore` just ignores the result of button#on_clicked -
     you can also do `let _ = button#on_clicked ... in ...` *)
  ignore
    (button#on_clicked
       ~callback:(fun () ->
         incr count;
         label#set_label (Printf.sprintf "Clicked %d times" !count))
       ());

  let box = Box.new_ `VERTICAL 12 in
  box#set_margin_top 12;
  box#set_margin_bottom 12;
  box#set_margin_start 12;
  box#set_margin_end 12;
  (* When appending the label and button, coerce them to the
     Widget.widget_t type *)
  box#append (label :> Widget.widget_t);
  box#append (button :> Widget.widget_t);

  window#set_child (Some (box :> Widget.widget_t));
  window#present ()

let () =
  let app = Application.new_ (Some "org.example.Counter") [ `DEFAULT_FLAGS ] in
  ignore (app#on_activate ~callback:(fun () -> activate app) ());
  exit (app#run 0 None)

Build and run

dune build
dune exec ./counter.exe

A window opens with a label and a button. Each click updates the label. Closing the window ends the program.

What the program does

  • The application. Ocgtk.Application starts GTK, runs the main loop, and quits when its last window closes. GTK emits its activate signal when the application starts, and that is where the window is built. The ID org.example.Counter names the application to the desktop. See The main loop and threads.
  • Creating objects. Each GTK class has a module (Ocgtk.Application_window, Ocgtk.Button, ...) with its constructors: Button.new_with_label wraps gtk_button_new_with_label. A constructor returns an OCaml object, and you call its methods with #: window#set_title.
  • Signals. button#on_clicked ~callback () connects a handler to the button's clicked signal. Don't leave out the final (): without it the handler is never connected. See Signals.
