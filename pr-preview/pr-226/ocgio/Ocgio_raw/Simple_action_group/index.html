Module Ocgio_raw.Simple_action_group

GSimpleActionGroup is a hash table filled with Gio.Action objects, implementing the Gio.ActionGroup and Gio.ActionMap interfaces.

The class built on this module is in Ocgio.Simple_action_group.

type t = [ `simple_action_group | `object_ ] Ocglib.Gobject.obj
val gtype : unit -> Ocglib.Gobject.Type.t
val new_ : unit -> t

Creates a new, empty, GSimpleActionGroup.

val remove : t -> string -> unit

Removes the named action from the action group.

If no action of this name is in the group then nothing happens.

val lookup : t -> string -> Action.t

Looks up the action with the name action_name in the group.

If no such action exists, returns None.

val insert : t -> Action.t -> unit

Adds an action to the action group.

If the action group already contains an action with the same name as action then the old action is dropped from the group.

The action group takes its own reference on action.
