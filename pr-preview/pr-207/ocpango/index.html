ocpango

The ocpango package provides OCaml bindings for Pango: text layout and internationalized font rendering. They are generated from Pango's GObject introspection data.

  • Modules
  • Dependencies

Modules

The library is reached as Ocpango, with one module per class, interface or record, such as Ocpango.Layout and Ocpango.Font_description.

  • All modules — every class, interface and record, grouped by kind.
  • Ocpango.Enums — enumerations and bitfields.
  • Ocpango.Constants — constants.
  • Ocpango.Raw — the C externals and abstract types the modules above are built on.

Dependencies

It builds on Ocglib (GLib and GObject), Occairo and Ocgio.
