ocgraphene

The ocgraphene package provides OCaml bindings for Graphene: lightweight 3D transform and geometry types (vectors, matrices, rectangles) used by Gsk and Gtk. They are generated from Graphene's GObject introspection data.

  • Modules
  • Dependencies

Modules

The library is reached as Ocgraphene, with one module per class, interface or record, such as Ocgraphene.Rect and Ocgraphene.Matrix.

  • All modules — every class, interface and record, grouped by kind.
  • Ocgraphene.Enums — enumerations and bitfields.
  • Ocgraphene.Constants — constants.
  • Ocgraphene.Raw — the C externals and abstract types the modules above are built on.

Dependencies

It builds on Ocglib (GLib and GObject).
