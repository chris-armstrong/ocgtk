Module Ocpangocairo.Font

PangoCairoFont is an interface exported by fonts for use with Cairo.

Its methods, signals and properties are on font_t. Its full description is under Description. Its constructors are under Constructors. The functions it is built on are in Ocpangocairo.Raw.Font.
