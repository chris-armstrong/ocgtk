Module Generate.Entity_doc

val l1_module : refs:Doc_resolve.env -> class_name:string -> class_doc:string option -> Doc_emit.t option

The layer 1 module's floating doc: the class doc, then a pointer to the layer 2 module. Without a class doc, it starts with "Bindings for class_name." instead, because the first paragraph is also the module's synopsis on its parent's page.

val l2_module : refs:Doc_resolve.env -> class_name:string -> class_doc:string option -> Doc_emit.t option

The layer 2 module's preamble, kept short so the declarations follow it closely: a synopsis, then where the members, the full description and the constructors are, and the layer 1 module it is built on. The synopsis is the class doc's first paragraph when that paragraph stands on its own, else "Bindings for class_name."; it is also the module's synopsis on its parent's page.

val class_heading : string

The floating Class heading before the layer 2 class type and class.

val description : refs:Doc_resolve.env -> class_name:string -> class_doc:string option -> Doc_emit.t option

The floating Description section after the class: a heading, then the whole class doc. None without a class doc, or when the synopsis is the whole of it.

type ancestor =
  1. | Bound of {
    1. namespace : string;
    2. name : string;
    }
    (*

    Has a layer 2 class type, linked through its own module.

    *)
  2. | Unbound of string
    (*

    No layer 2 class type; named as code, with its GIR name.

    *)

A class's parent, or an interface it implements or requires.

type inheritance = {
  1. parent : ancestor option;
  2. implements : ancestor list;
    (*

    Every interface the class implements, including those its parent already provides, which the class type does not inherit again.

    *)
  3. requires : ancestor list;
    (*

    An interface's prerequisites.

    *)
}
val no_inheritance : inheritance
val class_type : refs:Doc_resolve.env -> class_name:string -> inheritance:inheritance -> class_doc:string option -> Doc_emit.t option

The doc of the layer 2 class type: a bold line saying what it holds, the inheritance block (Inherits from, Implements, Requires, each left out when empty), then the class doc, so the class doc is on the class type's page as well as the module's.

val class_ : namespace:string -> class_name:string -> Doc_emit.t option

The canned doc of the layer 2 class: the layer 1 type it wraps.

type layer =
  1. | Layer1
  2. | Layer2
val combined_module : namespace:string -> layer:layer -> class_names:string list -> Doc_emit.t option

The floating doc of a module that defines a cycle's classes together: which modules re-export them, and that those are the ones to use.

val constructors_heading : string

The floating Constructors heading, with the constructors label the layer 2 module doc links to. Every layer 2 class module has one.

type instantiation =
  1. | Abstract_class
    (*

    GIR abstract="1".

    *)
  2. | Interface
  3. | Returned_only
    (*

    Any other class or record without a constructor.

    *)

Why a class has no constructors, which decides what its Constructors section says instead.

val no_constructors : instantiation -> Doc_emit.t option

The canned line under the Constructors heading of a class with no generated constructor.

val constructor : refs:Doc_resolve.env -> class_name:string -> Types.gir_constructor -> Doc_emit.t option

A constructor's doc at either layer: its translated GIR doc, else "Create a new class_name. Wraps c_function." with the C function linked to its gi-docgen page when the namespace has a gi-docgen site.

type accessor =
  1. | Getter
  2. | Setter
val property : refs:Doc_resolve.env -> class_name:string -> accessor:accessor -> Types.gir_property -> Doc_emit.t option

A property accessor's doc at either layer: the property's translated GIR doc, the same on its getter and setter, else a canned line: "Get property: name (Type, default value)." or "Set property: ...", then "Construct-only." when it is, and a link to the property's gi-docgen page when the namespace has a gi-docgen site.
