Module Ocgio.Output_message

Structure used for scatter/gather data output when sending multiple messages or packets in one go. You generally pass in an array of GOutputVectors and the operation will use all the buffers as if they were one buffer.

Description

Structure used for scatter/gather data output when sending multiple messages or packets in one go. You generally pass in an array of GOutputVectors and the operation will use all the buffers as if they were one buffer.

If address is None then the message is sent to the default receiver (as previously set by g_socket_connect ()).

Constructors

This class is not instantiated directly - it is used as a return value by methods on other classes.
