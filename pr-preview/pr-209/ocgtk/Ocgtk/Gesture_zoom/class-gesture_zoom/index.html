Class Gesture_zoom.gesture_zoom

Wraps a layer 1 handle, Ocgtk.Raw.Gesture_zoom.t. Apply it directly only to convert a handle obtained from layer 1: constructors, and methods that return a GtkGestureZoom, give one already wrapped.

inherit Ocgtk.Gesture.gesture_t
method on_scale_changed : ?after:bool -> callback:(scale:float -> unit) -> unit -> Ocglib.Gobject.Signal.handler_id

Emitted whenever the distance between both tracked sequences changes.

method get_scale_delta : unit -> float

Gets the scale delta.

If gesture is active, this function returns the zooming difference since the gesture was recognized (hence the starting point is considered 1:1). If gesture is not active, 1 is returned.
