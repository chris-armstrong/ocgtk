class numeric_sorter : Ocgtk.Raw.Numeric_sorter.t -> numeric_sorter_t

Wraps a layer 1 handle, Ocgtk.Raw.Numeric_sorter.t. Apply it directly only to convert a handle obtained from layer 1: constructors, and methods that return a GtkNumericSorter, give one already wrapped.

Description

Sorts items numerically.

To obtain the numbers to compare, this sorter evaluates a Gtk.Expression.

Constructors

val new_ : Expression.expression_t option -> numeric_sorter_t

Creates a new numeric sorter using the given expression.

Smaller numbers will be sorted first. You can call Gtk.NumericSorter.set_sort_order to change this.
