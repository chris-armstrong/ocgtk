Class Bitset_iter.bitset_iter

Wraps a layer 1 handle, Ocgtk.Raw.Bitset_iter.t. Apply it directly only to convert a handle obtained from layer 1: constructors, and methods that return a GtkBitsetIter, give one already wrapped.

method get_value : unit -> int

Gets the current value that iter points to.

If iter is not valid and Gtk.BitsetIter.is_valid returns FALSE, this function returns 0.

method is_valid : unit -> bool

Checks if iter points to a valid value.
