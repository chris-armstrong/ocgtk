Class Event_controller_scroll.event_controller_scroll

Wraps a raw handle of Ocgtk.Raw.Event_controller_scroll.t.

inherit Ocgtk.Event_controller_and__layout_child_and__layout_manager_and__root_and__tooltip_and__widget.event_controller_t
method on_decelerate : ?after:bool -> callback:(vel_x:float -> vel_y:float -> unit) -> unit -> Ocglib.Gobject.Signal.handler_id

Emitted after scroll is finished if the GTK_EVENT_CONTROLLER_SCROLL_KINETIC flag is set.

vel_x and vel_y express the initial velocity that was imprinted by the scroll events. vel_x and vel_y are expressed in pixels/ms.

method on_scroll : ?after:bool -> callback:(dx:float -> dy:float -> bool) -> unit -> Ocglib.Gobject.Signal.handler_id

Signals that the widget should scroll by the amount specified by dx and dy.

For the representation unit of the deltas, see Gtk.EventControllerScroll.get_unit.

method on_scroll_begin : ?after:bool -> callback:(unit -> unit) -> unit -> Ocglib.Gobject.Signal.handler_id

Signals that a new scrolling operation has begun.

It will only be emitted on devices capable of it.

method on_scroll_end : ?after:bool -> callback:(unit -> unit) -> unit -> Ocglib.Gobject.Signal.handler_id

Signals that a scrolling operation has finished.

It will only be emitted on devices capable of it.

method get_flags : unit -> Ocgtk.Enums.eventcontrollerscrollflags

Gets the flags conditioning the scroll controller behavior.

method get_unit : unit -> Ocgdk.Enums.scrollunit

Gets the scroll unit of the last Gtk.EventControllerScroll::scroll signal received.

Always returns GDK_SCROLL_UNIT_WHEEL if the GTK_EVENT_CONTROLLER_SCROLL_DISCRETE flag is set.

method set_flags : Ocgtk.Enums.eventcontrollerscrollflags -> unit

Sets the flags conditioning scroll controller behavior.
