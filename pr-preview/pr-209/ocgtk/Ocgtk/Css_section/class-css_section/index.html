Class Css_section.css_section

Wraps a layer 1 handle, Ocgtk.Raw.Css_section.t. Apply it directly only to convert a handle obtained from layer 1: constructors, and methods that return a GtkCssSection, give one already wrapped.

method get_bytes : unit -> Ocglib.Glib_bytes.t option

Gets the bytes that section was parsed from.

method get_end_location : unit -> Ocgtk.Raw.Css_location.t

Returns the location in the CSS document where this section ends.

method get_file : unit -> Ocgio.File.file_t option

Gets the file that section was parsed from.

If no such file exists, for example because the CSS was loaded via Gtk.CssProvider.load_from_data, then NULL is returned.

method get_parent : unit -> Ocgtk.Raw.Css_section.t option

Gets the parent section for the given section.

The parent section is the section that contains this section. A special case are sections of type GTK_CSS_SECTION_DOCUMENT. Their parent will either be NULL if they are the original CSS document that was loaded by Gtk.CssProvider.load_from_file or a section of type GTK_CSS_SECTION_IMPORT if it was loaded with an @import rule from a different file.

method get_start_location : unit -> Ocgtk.Raw.Css_location.t

Returns the location in the CSS document where this section starts.

method ref : unit -> Ocgtk.Raw.Css_section.t

Increments the reference count on section.

method to_string : unit -> string

Prints the section into a human-readable text form using Gtk.CssSection.print.
