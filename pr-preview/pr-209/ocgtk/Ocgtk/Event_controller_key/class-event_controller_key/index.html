Class Event_controller_key.event_controller_key

Wraps a layer 1 handle, Ocgtk.Raw.Event_controller_key.t. Apply it directly only to convert a handle obtained from layer 1: constructors, and methods that return a GtkEventControllerKey, give one already wrapped.
