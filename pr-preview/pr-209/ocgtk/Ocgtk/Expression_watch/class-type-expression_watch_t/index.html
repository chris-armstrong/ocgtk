Class type Expression_watch.expression_watch_t

The methods, signals and properties of a GtkExpressionWatch.

method evaluate : Ocglib.Gobject.Value.t -> bool

Evaluates the watched expression and on success stores the result in value.

This is equivalent to calling Gtk.Expression.evaluate with the expression and this pointer originally used to create watch.

method ref : unit -> Ocgtk.Raw.Expression_watch.t

Acquires a reference on the given GtkExpressionWatch.

method unwatch : unit -> unit

Stops watching an expression.

See Gtk.Expression.watch for how the watch was established.
