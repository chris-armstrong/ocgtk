Description

Represents the columns in a GtkColumnView.

The main ingredient for a GtkColumnViewColumn is the GtkListItemFactory that tells the columnview how to create cells for this column from items in the model.

Columns have a title, and can optionally have a header menu set with Gtk.ColumnViewColumn.set_header_menu.

A sorter can be associated with a column using Gtk.ColumnViewColumn.set_sorter, to let users influence sorting by clicking on the column header.

Creates a new GtkColumnViewColumn that uses the given factory for mapping items to widgets.

You most likely want to call Gtk.ColumnView.append_column next.

The function takes ownership of the argument, so you can write code like:

column = gtk_column_view_column_new (_("Name"),
  gtk_builder_list_item_factory_new_from_resource ("/name.ui"));
