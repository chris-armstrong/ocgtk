Class Gesture_rotate.gesture_rotate

Wraps a layer 1 handle, Ocgtk.Raw.Gesture_rotate.t. Apply it directly only to convert a handle obtained from layer 1: constructors, and methods that return a GtkGestureRotate, give one already wrapped.

method get_angle_delta : unit -> float

Gets the angle delta in radians.

If gesture is active, this function returns the angle difference in radians since the gesture was first recognized. If gesture is not active, 0 is returned.
