Class Statusbar.statusbar

Wraps a layer 1 handle, Ocgtk.Raw.Statusbar.t. Apply it directly only to convert a handle obtained from layer 1: constructors, and methods that return a GtkStatusbar, give one already wrapped.

inherit Ocgtk.Event_controller_and__layout_child_and__layout_manager_and__root_and__tooltip_and__widget.widget_t
method on_text_popped : ?after:bool -> callback:(context_id:int -> text:string -> unit) -> unit -> Ocglib.Gobject.Signal.handler_id

Emitted whenever a new message is popped off a statusbar's stack.

method on_text_pushed : ?after:bool -> callback:(context_id:int -> text:string -> unit) -> unit -> Ocglib.Gobject.Signal.handler_id

Emitted whenever a new message gets pushed onto a statusbar's stack.

method get_context_id : string -> int

Returns a new context identifier, given a description of the actual context.

Note that the description is not shown in the UI.

method pop : int -> unit

Removes the first message in the GtkStatusbar’s stack with the given context id.

Note that this may not change the displayed message, if the message at the top of the stack has a different context id.

method push : int -> string -> int

Pushes a new message onto a statusbar’s stack.

method remove : int -> int -> unit

Forces the removal of a message from a statusbar’s stack. The exact context_id and message_id must be specified.

method remove_all : int -> unit

Forces the removal of all messages from a statusbar's stack with the exact context_id.

method as_statusbar : Ocgtk.Raw.Statusbar.t
