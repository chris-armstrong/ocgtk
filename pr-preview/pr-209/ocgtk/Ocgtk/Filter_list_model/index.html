Module Ocgtk.Filter_list_model

A list model that filters the elements of another model.

It hides some elements from the underlying model according to criteria given by a GtkFilter.

The model can be set up to do incremental filtering, so that filtering long lists doesn't block the UI. See Gtk.FilterListModel.set_incremental for details.

GtkFilterListModel passes through sections from the underlying model.

Its methods, signals and properties are on filter_list_model_t. Its constructors are under Constructors. The functions it is built on are in Ocgtk.Raw.Filter_list_model.
