method get_child_revealed : unit -> bool

Returns whether the child is fully revealed.

In other words, this returns whether the transition to the revealed state is completed.

method get_reveal_child : unit -> bool

Returns whether the child is currently revealed.

This function returns TRUE as soon as the transition is to the revealed state is started. To learn whether the child is fully revealed (ie the transition is completed), use Gtk.Revealer.get_child_revealed.
