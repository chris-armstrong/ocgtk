Class Bookmark_list.bookmark_list

Wraps a layer 1 handle, Ocgtk.Raw.Bookmark_list.t. Apply it directly only to convert a handle obtained from layer 1: constructors, and methods that return a GtkBookmarkList, give one already wrapped.

inherit Ocgio.List_model.list_model_t
method get_attributes : unit -> string option

Gets the attributes queried on the children.

method get_filename : unit -> string

Returns the filename of the bookmark file that this list is loading.

method get_io_priority : unit -> int

Gets the IO priority to use while loading file.

method is_loading : unit -> bool

Returns TRUE if the files are currently being loaded.

Files will be added to self from time to time while loading is going on. The order in which are added is undefined and may change in between runs.

method set_attributes : string option -> unit

Sets the attributes to be enumerated and starts the enumeration.

If attributes is NULL, no attributes will be queried, but a list of GFileInfos will still be created.

method set_io_priority : int -> unit

Sets the IO priority to use while loading files.

The default IO priority is G_PRIORITY_DEFAULT.
