Class List_view.list_view

Wraps a layer 1 handle, Ocgtk.Raw.List_view.t. Apply it directly only to convert a handle obtained from layer 1: constructors, and methods that return a GtkListView, give one already wrapped.

inherit Ocgtk.List_base.list_base_t
method on_activate : ?after:bool -> callback:(position:int -> unit) -> unit -> Ocglib.Gobject.Signal.handler_id

Emitted when a row has been activated by the user.

Activation usually happens via the list.activate-item action of the GtkListView.

This allows for a convenient way to handle activation in a listview. See Gtk.ListItem.set_activatable for details on how to use this signal.
