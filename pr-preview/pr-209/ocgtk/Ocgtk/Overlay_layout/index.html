Module Ocgtk.Overlay_layout

The layout manager used by Gtk.Overlay.

It places widgets as overlays on top of the main child.

This is not a reusable layout manager, since it expects its widget to be a GtkOverlay. It is only listed here so that its layout properties get documented.

Its methods, signals and properties are on overlay_layout_t. Its constructors are under Constructors. The functions it is built on are in Ocgtk.Raw.Overlay_layout.
