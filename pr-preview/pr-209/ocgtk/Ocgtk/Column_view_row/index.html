Module Ocgtk.Column_view_row

Configures how rows are displayed in a Gtk.ColumnView.

It is not used to set the widgets displayed in the individual cells. For that see GtkColumnViewColumn.set_factory and GtkColumnViewCell.

Its methods, signals and properties are on column_view_row_t. The functions it is built on are in Ocgtk.Raw.Column_view_row.
