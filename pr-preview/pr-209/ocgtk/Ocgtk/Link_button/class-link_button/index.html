Class Link_button.link_button

Wraps a layer 1 handle, Ocgtk.Raw.Link_button.t. Apply it directly only to convert a handle obtained from layer 1: constructors, and methods that return a GtkLinkButton, give one already wrapped.

inherit Ocgtk.Button.button_t
method on_activate_link : ?after:bool -> callback:(unit -> bool) -> unit -> Ocglib.Gobject.Signal.handler_id

Emitted each time the GtkLinkButton is clicked.

The default handler will call Gtk.FileLauncher.launch with the URI stored inside the Gtk.LinkButton:uri property.

To override the default behavior, you can connect to the ::activate-link signal and stop the propagation of the signal by returning TRUE from your handler.

method get_uri : unit -> string

Retrieves the URI of the GtkLinkButton.

method get_visited : unit -> bool

Retrieves the “visited” state of the GtkLinkButton.

The button becomes visited when it is clicked. If the URI is changed on the button, the “visited” state is unset again.

The state may also be changed using Gtk.LinkButton.set_visited.

method set_uri : string -> unit

Sets uri as the URI where the GtkLinkButton points.

As a side-effect this unsets the “visited” state of the button.

method set_visited : bool -> unit

Sets the “visited” state of the GtkLinkButton.

See Gtk.LinkButton.get_visited for more details.

method as_link_button : Ocgtk.Raw.Link_button.t
