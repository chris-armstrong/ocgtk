Module Generate.Entity_doc

val l1_module : namespace:string -> class_name:string -> c_type:string -> class_doc:string option -> Doc_emit.t option

The layer 1 module's floating doc: the class doc, then a pointer to the layer 2 module. Without a class doc, it starts with "Bindings for c_type." instead, because the first paragraph is also the module's synopsis on its parent's page.

val l2_module : namespace:string -> class_name:string -> c_type:string -> has_constructors:bool -> class_doc:string option -> Doc_emit.t option

The layer 2 module's floating doc: the class doc, then where its members are (the class type) and the layer 1 module it is built on.

val class_type : c_type:string -> Doc_emit.t option

The canned doc of the layer 2 class type.

val class_ : namespace:string -> class_name:string -> c_type:string -> Doc_emit.t option

The canned doc of the layer 2 class: when to apply it directly.

type layer =
  1. | Layer1
  2. | Layer2
val combined_module : namespace:string -> layer:layer -> class_names:string list -> Doc_emit.t option

The floating doc of a module that defines a cycle's classes together: which modules re-export them, and that those are the ones to use.

val constructors_heading : string

The floating Constructors heading, with the constructors label the layer 2 module doc links to.

val constructor : namespace:string -> class_name:string -> c_type:string -> Types.gir_constructor -> Doc_emit.t option

A constructor's doc at either layer: its translated GIR doc, else "Create a new c_type. Wraps c_function." with the C function linked to its gi-docgen page when the namespace has a gi-docgen site.

type accessor =
  1. | Getter
  2. | Setter
val property : accessor:accessor -> Types.gir_property -> Doc_emit.t option

A property accessor's doc at either layer: the property's translated GIR doc, the same on its getter and setter, else "Get property: <name>" or "Set property: <name>".
