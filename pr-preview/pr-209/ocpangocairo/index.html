ocpangocairo

The ocpangocairo package provides OCaml bindings for PangoCairo, the glue between Pango text layout and Cairo rendering. They are generated from PangoCairo's GObject introspection data.

  • Modules
  • Dependencies

Modules

The library is reached as Ocpangocairo, with one module per class, interface or record, such as Ocpangocairo.Font and Ocpangocairo.Font_map.

All interfaces

  • Ocpangocairo.Enums — enumerations and bitfields.
  • Ocpangocairo.Raw — the C externals and abstract types the modules above are built on.

Dependencies

It builds on Ocglib (GLib and GObject), Occairo, Ocgio and Ocpango.
