Module Ocpango.Script_iter

A PangoScriptIter is used to iterate through a string and identify ranges in different scripts.

Its methods, signals and properties are on script_iter_t. Its constructors are under Constructors. The functions it is built on are in Ocpango.Raw.Script_iter.

class script_iter : Ocpango.Raw.Script_iter.t -> script_iter_t

Wraps a layer 1 handle, Ocpango.Raw.Script_iter.t. Apply it directly only to convert a handle obtained from layer 1: constructors, and methods that return a PangoScriptIter, give one already wrapped.

Constructors

val new_ : string -> int -> script_iter_t

Create a new PangoScriptIter, used to break a string of Unicode text into runs by Unicode script.

No copy is made of text, so the caller needs to make sure it remains valid until the iterator is freed with Pango.ScriptIter.free.
