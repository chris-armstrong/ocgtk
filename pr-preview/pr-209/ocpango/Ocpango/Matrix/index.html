class matrix : Ocpango.Raw.Matrix.t -> matrix_t

Wraps a layer 1 handle, Ocpango.Raw.Matrix.t. Apply it directly only to convert a handle obtained from layer 1: constructors, and methods that return a PangoMatrix, give one already wrapped.

Description

A PangoMatrix specifies a transformation between user-space and device coordinates.

The transformation is given by

x_device = x_user * matrix->xx + y_user * matrix->xy + matrix->x0;
y_device = x_user * matrix->yx + y_user * matrix->yy + matrix->y0;
