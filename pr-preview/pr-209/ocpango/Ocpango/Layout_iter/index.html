class layout_iter : Ocpango.Raw.Layout_iter.t -> layout_iter_t

Wraps a layer 1 handle, Ocpango.Raw.Layout_iter.t. Apply it directly only to convert a handle obtained from layer 1: constructors, and methods that return a PangoLayoutIter, give one already wrapped.

Description

A PangoLayoutIter can be used to iterate over the visual extents of a PangoLayout.

To obtain a PangoLayoutIter, use Pango.Layout.get_iter.

The PangoLayoutIter structure is opaque, and has no user-visible fields.
