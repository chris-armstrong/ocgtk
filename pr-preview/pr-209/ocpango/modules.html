Pango classes and records

Ocpango has one module for each Pango class and record. The externals they are built on are in Ocpango.Raw.

  • Classes
  • Records

Classes

  • Ocpango.Context A PangoContext stores global information used to control the itemization process.
  • Ocpango.Coverage A PangoCoverage structure is a map from Unicode characters to Pango.CoverageLevel values.
  • Ocpango.Font A PangoFont is used to represent a font in a rendering-system-independent manner.
  • Ocpango.Font_face A PangoFontFace is used to represent a group of fonts with the same family, slant, weight, and width, but varying sizes.
  • Ocpango.Font_family A PangoFontFamily is used to represent a family of related font faces.
  • Ocpango.Font_map A PangoFontMap represents the set of fonts available for a particular rendering system.
  • Ocpango.Fontset A PangoFontset represents a set of PangoFont to use when rendering text.
  • Ocpango.Fontset_simple PangoFontsetSimple is a implementation of the abstract PangoFontset base class as an array of fonts.
  • Ocpango.Layout A PangoLayout structure represents an entire paragraph of text.
  • Ocpango.Renderer PangoRenderer is a base class for objects that can render text provided as PangoGlyphString or PangoLayout.

Records

  • Ocpango.Analysis The PangoAnalysis structure stores information about the properties of a segment of text.
  • Ocpango.Attr_class The PangoAttrClass structure stores the type and operations for a particular type of attribute.
  • Ocpango.Attr_color The PangoAttrColor structure is used to represent attributes that are colors.
  • Ocpango.Attr_float The PangoAttrFloat structure is used to represent attributes with a float or double value.
  • Ocpango.Attr_font_desc The PangoAttrFontDesc structure is used to store an attribute that sets all aspects of the font description at once.
  • Ocpango.Attr_font_features The PangoAttrFontFeatures structure is used to represent OpenType font features as an attribute.
  • Ocpango.Attr_int The PangoAttrInt structure is used to represent attributes with an integer or enumeration value.
  • Ocpango.Attr_iterator A PangoAttrIterator is used to iterate through a PangoAttrList.
  • Ocpango.Attr_language The PangoAttrLanguage structure is used to represent attributes that are languages.
  • Ocpango.Attr_list A PangoAttrList represents a list of attributes that apply to a section of text.
  • Ocpango.Attr_shape The PangoAttrShape structure is used to represent attributes which impose shape restrictions.
  • Ocpango.Attr_size The PangoAttrSize structure is used to represent attributes which set font size.
  • Ocpango.Attr_string The PangoAttrString structure is used to represent attributes with a string value.
  • Ocpango.Attribute The PangoAttribute structure represents the common portions of all attributes.
  • Ocpango.Color The PangoColor structure is used to represent a color in an uncalibrated RGB color-space.
  • Ocpango.Font_description A PangoFontDescription describes a font in an implementation-independent manner.
  • Ocpango.Font_metrics A PangoFontMetrics structure holds the overall metric information for a font.
  • Ocpango.Glyph_geometry The PangoGlyphGeometry structure contains width and positioning information for a single glyph.
  • Ocpango.Glyph_info A PangoGlyphInfo structure represents a single glyph with positioning information and visual attributes.
  • Ocpango.Glyph_item A PangoGlyphItem is a pair of a PangoItem and the glyphs resulting from shaping the items text.
  • Ocpango.Glyph_item_iter A PangoGlyphItemIter is an iterator over the clusters in a PangoGlyphItem.
  • Ocpango.Glyph_string A PangoGlyphString is used to store strings of glyphs with geometry and visual attribute information.
  • Ocpango.Glyph_vis_attr A PangoGlyphVisAttr structure communicates information between the shaping and rendering phases.
  • Ocpango.Item The PangoItem structure stores information about a segment of text.
  • Ocpango.Language The PangoLanguage structure is used to represent a language.
  • Ocpango.Layout_iter A PangoLayoutIter can be used to iterate over the visual extents of a PangoLayout.
  • Ocpango.Layout_line A PangoLayoutLine represents one of the lines resulting from laying out a paragraph via PangoLayout.
  • Ocpango.Log_attr The PangoLogAttr structure stores information about the attributes of a single character.
  • Ocpango.Matrix A PangoMatrix specifies a transformation between user-space and device coordinates.
  • Ocpango.Rectangle The PangoRectangle structure represents a rectangle.
  • Ocpango.Script_iter A PangoScriptIter is used to iterate through a string and identify ranges in different scripts.
  • Ocpango.Tab_array A PangoTabArray contains an array of tab stops.
