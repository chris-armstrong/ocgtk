Class Zlib_compressor.zlib_compressor

Wraps a layer 1 handle, Ocgio.Raw.Zlib_compressor.t. Apply it directly only to convert a handle obtained from layer 1: constructors, and methods that return a GZlibCompressor, give one already wrapped.
