Module Ocgio.Io_extension

GIOExtension is an opaque data structure and can only be accessed using the following functions.

Its methods, signals and properties are on io_extension_t. The functions it is built on are in Ocgio.Raw.Io_extension.

class type io_extension_t = object ... end

The methods, signals and properties of a GIOExtension.

class io_extension : Ocgio.Raw.Io_extension.t -> io_extension_t

Wraps a layer 1 handle, Ocgio.Raw.Io_extension.t. Apply it directly only to convert a handle obtained from layer 1: constructors, and methods that return a GIOExtension, give one already wrapped.
