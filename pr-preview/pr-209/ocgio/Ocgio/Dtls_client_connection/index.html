Module Ocgio.Dtls_client_connection

GDtlsClientConnection is the client-side subclass of Gio.DtlsConnection, representing a client-side DTLS connection.

Its methods, signals and properties are on dtls_client_connection_t. The functions it is built on are in Ocgio.Raw.Dtls_client_connection.

class dtls_client_connection : Ocgio.Raw.Dtls_client_connection.t -> dtls_client_connection_t

Wraps a layer 1 handle, Ocgio.Raw.Dtls_client_connection.t. Apply it directly only to convert a handle obtained from layer 1: constructors, and methods that return a GDtlsClientConnection, give one already wrapped.
