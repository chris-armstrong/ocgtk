Module Ocgio.Tls_connection

GTlsConnection is the base TLS connection class type, which wraps a Gio.IOStream and provides TLS encryption on top of it. Its subclasses, Gio.TlsClientConnection and Gio.TlsServerConnection, implement client-side and server-side TLS, respectively.

Its methods, signals and properties are on tls_connection_t. Its full description is under Description. The functions it is built on are in Ocgio.Raw.Tls_connection.

Description

GTlsConnection is the base TLS connection class type, which wraps a Gio.IOStream and provides TLS encryption on top of it. Its subclasses, Gio.TlsClientConnection and Gio.TlsServerConnection, implement client-side and server-side TLS, respectively.

For DTLS (Datagram TLS) support, see Gio.DtlsConnection.
