Module Ocgio.D_bus_object

The GDBusObject type is the base type for D-Bus objects on both the service side (see Gio.DBusObjectSkeleton) and the client side (see Gio.DBusObjectProxy). It is essentially just a container of interfaces.

Its methods, signals and properties are on d_bus_object_t. The functions it is built on are in Ocgio.Raw.D_bus_object.
