Module Ocgio.D_bus_method_invocation

Instances of the GDBusMethodInvocation class are used when handling D-Bus method calls. It provides a way to asynchronously return results and errors.

Its methods, signals and properties are on d_bus_method_invocation_t. Its full description is under Description. The functions it is built on are in Ocgio.Raw.D_bus_method_invocation.

Description

Instances of the GDBusMethodInvocation class are used when handling D-Bus method calls. It provides a way to asynchronously return results and errors.

The normal way to obtain a GDBusMethodInvocation object is to receive it as an argument to the handle_method_call() function in a Gio.DBusInterfaceVTable that was passed to Gio.DBusConnection.register_object.
