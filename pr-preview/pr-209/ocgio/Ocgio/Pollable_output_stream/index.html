Module Ocgio.Pollable_output_stream

GPollableOutputStream is implemented by Gio.OutputStreams that can be polled for readiness to write. This can be used when interfacing with a non-GIO API that expects UNIX-file-descriptor-style asynchronous I/O rather than GIO-style.

Its methods, signals and properties are on pollable_output_stream_t. Its full description is under Description. The functions it is built on are in Ocgio.Raw.Pollable_output_stream.

Description

GPollableOutputStream is implemented by Gio.OutputStreams that can be polled for readiness to write. This can be used when interfacing with a non-GIO API that expects UNIX-file-descriptor-style asynchronous I/O rather than GIO-style.

Some classes may implement GPollableOutputStream but have only certain instances of that class be pollable. If Gio.PollableOutputStream.can_poll returns false, then the behavior of other GPollableOutputStream methods is undefined.
