Module Ocgio.Loadable_icon

GLoadableIcon extends the Gio.Icon interface and adds the ability to load icons from streams.

Its methods, signals and properties are on loadable_icon_t. The functions it is built on are in Ocgio.Raw.Loadable_icon.
