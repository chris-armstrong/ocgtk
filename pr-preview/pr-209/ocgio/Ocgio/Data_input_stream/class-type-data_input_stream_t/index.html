Class type Data_input_stream.data_input_stream_t

The methods, signals and properties of a DataInputStream.

Data input stream implements Gio.InputStream and includes functions for reading structured data directly from a binary input stream.

method read_int16 : Ocgio.Cancellable.cancellable_t option -> (Ocglib.Int16.t, Ocglib.GError.t) Stdlib.result

Reads a 16-bit/2-byte value from stream.

In order to get the correct byte order for this read operation, see g_data_input_stream_get_byte_order() and g_data_input_stream_set_byte_order().

method read_int32 : Ocgio.Cancellable.cancellable_t option -> (Ocglib.Int32.t, Ocglib.GError.t) Stdlib.result

Reads a signed 32-bit/4-byte value from stream.

In order to get the correct byte order for this read operation, see g_data_input_stream_get_byte_order() and g_data_input_stream_set_byte_order().

If cancellable is not NULL, then the operation can be cancelled by triggering the cancellable object from another thread. If the operation was cancelled, the error G_IO_ERROR_CANCELLED will be returned.

method set_byte_order : Ocgio.Enums.datastreambyteorder -> unit

method set_newline_type : Ocgio.Enums.datastreamnewlinetype -> unit

Sets the newline type for the stream.

Note that using G_DATA_STREAM_NEWLINE_TYPE_ANY is slightly unsafe. If a read chunk ends in "CR" we must read an additional byte to know if this is "CR" or "CR LF", and this might block if there is no more data available.
