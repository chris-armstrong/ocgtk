Module Ocgio.Threaded_resolver

GThreadedResolver is an implementation of GResolver which calls the libc lookup functions in threads to allow them to run asynchronously.

Its methods, signals and properties are on threaded_resolver_t. The functions it is built on are in Ocgio.Raw.Threaded_resolver.
