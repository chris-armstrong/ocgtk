Module Ocgio.Action_entry

This struct defines a single action. It is for use with Gio.ActionMap.add_action_entries.

The order of the items in the structure are intended to reflect frequency of use. It is permissible to use an incomplete initialiser in order to leave some of the later values as NULL. All values after name are optional. Additional optional fields may be added in the future.

See Gio.ActionMap.add_action_entries for an example.

Its methods, signals and properties are on action_entry_t. The functions it is built on are in Ocgio.Raw.Action_entry.
