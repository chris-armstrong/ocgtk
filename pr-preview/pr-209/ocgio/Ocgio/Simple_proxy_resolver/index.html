Module Ocgio.Simple_proxy_resolver

GSimpleProxyResolver is a simple Gio.ProxyResolver implementation that handles a single default proxy, multiple URI-scheme-specific proxies, and a list of hosts that proxies should not be used for.

GSimpleProxyResolver is never the default proxy resolver, but it can be used as the base class for another proxy resolver implementation, or it can be created and used manually, such as with Gio.SocketClient.set_proxy_resolver.

Its methods, signals and properties are on simple_proxy_resolver_t. The functions it is built on are in Ocgio.Raw.Simple_proxy_resolver.
