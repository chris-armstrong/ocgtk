Module Ocgio.Tls_backend

TLS (Transport Layer Security, aka SSL) and DTLS backend. This is an internal type used to coordinate the different classes implemented by a TLS backend.

Its methods, signals and properties are on tls_backend_t. The functions it is built on are in Ocgio.Raw.Tls_backend.

class type tls_backend_t = object ... end

The methods, signals and properties of a GTlsBackend.

class tls_backend : Ocgio.Raw.Tls_backend.t -> tls_backend_t

Wraps a layer 1 handle, Ocgio.Raw.Tls_backend.t. Apply it directly only to convert a handle obtained from layer 1: constructors, and methods that return a GTlsBackend, give one already wrapped.
