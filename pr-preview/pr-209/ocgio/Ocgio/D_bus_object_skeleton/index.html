Module Ocgio.D_bus_object_skeleton

A GDBusObjectSkeleton instance is essentially a group of D-Bus interfaces. The set of exported interfaces on the object may be dynamic and change at runtime.

This type is intended to be used with Gio.DBusObjectManager.

Its methods, signals and properties are on d_bus_object_skeleton_t. Its constructors are under Constructors. The functions it is built on are in Ocgio.Raw.D_bus_object_skeleton.
