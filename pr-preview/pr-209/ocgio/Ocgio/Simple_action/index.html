Module Ocgio.Simple_action

A GSimpleAction is the obvious simple implementation of the Gio.Action interface. This is the easiest way to create an action for purposes of adding it to a Gio.SimpleActionGroup.

Its methods, signals and properties are on simple_action_t. Its constructors are under Constructors. The functions it is built on are in Ocgio.Raw.Simple_action.

Wraps a layer 1 handle, Ocgio.Raw.Simple_action.t. Apply it directly only to convert a handle obtained from layer 1: constructors, and methods that return a GSimpleAction, give one already wrapped.

Creates a new action.

The created action is stateless. See g_simple_action_new_stateful() to create an action that has state.

val new_stateful : string -> Ocglib.Gvariant_type.t option -> Ocglib.Gvariant.t -> simple_action_t

Creates a new stateful action.

All future state values must have the same GVariantType as the initial state.

If the state GVariant is floating, it is consumed.
