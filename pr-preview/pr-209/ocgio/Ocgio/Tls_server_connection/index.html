Module Ocgio.Tls_server_connection

GTlsServerConnection is the server-side subclass of Gio.TlsConnection, representing a server-side TLS connection.

Its methods, signals and properties are on tls_server_connection_t. The functions it is built on are in Ocgio.Raw.Tls_server_connection.

The methods, signals and properties of a GTlsServerConnection.

class tls_server_connection : Ocgio.Raw.Tls_server_connection.t -> tls_server_connection_t

Wraps a layer 1 handle, Ocgio.Raw.Tls_server_connection.t. Apply it directly only to convert a handle obtained from layer 1: constructors, and methods that return a GTlsServerConnection, give one already wrapped.
