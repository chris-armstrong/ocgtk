ocgdk

The ocgdk package provides OCaml bindings for GDK 4: the low-level windowing, displays, input and events that GTK is built on. They are generated from GDK's GObject introspection data.

  • Modules
  • Dependencies

Modules

The library is reached as Ocgdk, with one module per class, interface or record, such as Ocgdk.Display and Ocgdk.Texture.

  • All modules — every class, interface and record, grouped by kind.
  • Ocgdk.Enums — enumerations and bitfields.
  • Ocgdk.Constants — constants.
  • Ocgdk.Raw — the C externals and abstract types the modules above are built on.

Dependencies

It builds on Ocglib (GLib and GObject), Occairo, Ocgdkpixbuf, Ocgio, Ocpango and Ocpangocairo.
