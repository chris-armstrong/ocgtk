Description

Represents the platform-specific Vulkan draw context.

GdkVulkanContexts are created for a surface using Gdk.Surface.create_vulkan_context, and the context will match the characteristics of the surface.

Support for GdkVulkanContext is platform-specific and context creation can fail, returning NULL context.
