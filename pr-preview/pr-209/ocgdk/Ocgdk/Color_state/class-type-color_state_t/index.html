Class type Color_state.color_state_t

The methods, signals and properties of a GdkColorState.

method create_cicp_params : unit -> Ocgdk.Cicp_params_and__color_state.cicp_params_t option

Create a Gdk.CicpParams representing the colorstate.

It is not guaranteed that every GdkColorState can be represented with Cicp parameters. If that is the case, this function returns NULL.

method equal : Ocgdk.Raw.Color_state.t -> bool

Compares two GdkColorStates for equality.

Note that this function is not guaranteed to be perfect and two objects describing the same color state may compare not equal. However, different color states will never compare equal.

method equivalent : Ocgdk.Raw.Color_state.t -> bool

Compares two GdkColorStates for equivalence.

Two objects that represent the same color state should be equivalent, even though they may not be equal in the sense of Gdk.ColorState.equal.

method ref : unit -> Ocgdk.Raw.Color_state.t

Increase the reference count of self.
