class dmabuf_texture : Ocgdk.Raw.Dmabuf_texture.t -> dmabuf_texture_t

Wraps a layer 1 handle, Ocgdk.Raw.Dmabuf_texture.t. Apply it directly only to convert a handle obtained from layer 1: constructors, and methods that return a GdkDmabufTexture, give one already wrapped.

Description

A GdkTexture representing a DMA buffer.

To create a GdkDmabufTexture, use the auxiliary Gdk.DmabufTextureBuilder object.

Dma-buf textures can only be created on Linux.
