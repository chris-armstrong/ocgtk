Class Cicp_params.cicp_params

Wraps a layer 1 handle, Ocgdk.Raw.Cicp_params.t. Apply it directly only to convert a handle obtained from layer 1: constructors, and methods that return a GdkCicpParams, give one already wrapped.

method build_color_state : unit -> (Ocgdk.Raw.Color_state.t, Ocglib.GError.t) Stdlib.result

Creates a new GdkColorState object for the cicp parameters in self.

Note that this may fail if the cicp parameters in self are not supported by GTK. In that case, NULL is returned, and error is set with an error message that can be presented to the user.
