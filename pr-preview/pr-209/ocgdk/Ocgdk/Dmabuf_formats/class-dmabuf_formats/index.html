Class Dmabuf_formats.dmabuf_formats

Wraps a layer 1 handle, Ocgdk.Raw.Dmabuf_formats.t. Apply it directly only to convert a handle obtained from layer 1: constructors, and methods that return a GdkDmabufFormats, give one already wrapped.

method contains : Ocglib.UInt32.t -> Ocglib.UInt64.t -> bool

Returns whether a given format is contained in formats.

method equal : Ocgdk.Raw.Dmabuf_formats.t option -> bool

Returns whether formats1 and formats2 contain the same dmabuf formats, in the same order.

method get_n_formats : unit -> Ocglib.Gsize.t

Returns the number of formats that the formats object contains.

Note that DMA buffers are a Linux concept, so on other platforms, Gdk.DmabufFormats.get_n_formats will always return zero.

method ref : unit -> Ocgdk.Raw.Dmabuf_formats.t

Increases the reference count of formats.
