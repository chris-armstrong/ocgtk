Class Content_formats_builder.content_formats_builder

Wraps a layer 1 handle, Ocgdk.Raw.Content_formats_builder.t. Apply it directly only to convert a handle obtained from layer 1: constructors, and methods that return a GdkContentFormatsBuilder, give one already wrapped.

method add_formats : Ocgdk.Raw.Content_formats.t -> unit

Appends all formats from formats to builder, skipping those that already exist.

method add_gtype : Ocglib.Gobject.Type.t -> unit

Appends type to builder if it has not already been added.

method add_mime_type : string -> unit

Appends mime_type to builder if it has not already been added.

method ref : unit -> Ocgdk.Raw.Content_formats_builder.t

Acquires a reference on the given builder.

This function is intended primarily for bindings. GdkContentFormatsBuilder objects should not be kept around.

method to_formats : unit -> Ocgdk.Raw.Content_formats.t

Creates a new GdkContentFormats from the given builder.

The given GdkContentFormatsBuilder is reset once this function returns; you cannot call this function multiple times on the same builder instance.

This function is intended primarily for bindings. C code should use Gdk.ContentFormatsBuilder.free_to_formats.
