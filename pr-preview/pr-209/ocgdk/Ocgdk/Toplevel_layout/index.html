Module Ocgdk.Toplevel_layout

Contains information that is necessary to present a sovereign window on screen.

The GdkToplevelLayout struct is necessary for using Gdk.Toplevel.present.

Toplevel surfaces are sovereign windows that can be presented to the user in various states (maximized, on all workspaces, etc).

Its methods, signals and properties are on toplevel_layout_t. Its constructors are under Constructors. The functions it is built on are in Ocgdk.Raw.Toplevel_layout.
