Class type Content_provider.content_provider_t

The methods, signals and properties of a ContentProvider.

Provides content for the clipboard or for drag-and-drop operations in a number of formats.

To create a GdkContentProvider, use Gdk.ContentProvider.new_for_value or Gdk.ContentProvider.new_for_bytes.

GDK knows how to handle common text and image formats out-of-the-box. See Gdk.ContentSerializer and Gdk.ContentDeserializer if you want to add support for application-specific data formats.

method ref_storable_formats : unit -> Ocgdk.Raw.Content_formats.t

Gets the formats that the provider suggests other applications to store the data in.

An example of such an application would be a clipboard manager.

This can be assumed to be a subset of Gdk.ContentProvider.ref_formats.
