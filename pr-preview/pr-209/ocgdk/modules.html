Gdk classes, interfaces and records

Ocgdk has one module for each Gdk class, interface and record. The externals they are built on are in Ocgdk.Raw.

  • Classes
  • Interfaces
  • Records

Classes

  • Ocgdk.App_launch_context Handles launching an application in a graphical context.
  • Ocgdk.Button_event An event related to a button on a pointer device.
  • Ocgdk.Cairo_context Represents the platform-specific draw context.
  • Ocgdk.Cicp_params Contains the parameters that define a colorstate with cicp parameters.
  • Ocgdk.Clipboard Represents data shared between applications or inside an application.
  • Ocgdk.Content_deserializer Deserializes content received via inter-application data transfers.
  • Ocgdk.Content_provider Provides content for the clipboard or for drag-and-drop operations in a number of formats.
  • Ocgdk.Content_serializer Serializes content for inter-application data transfers.
  • Ocgdk.Crossing_event An event caused by a pointing device moving between surfaces.
  • Ocgdk.Cursor Used to create and destroy cursors.
  • Ocgdk.Delete_event An event related to closing a top-level surface.
  • Ocgdk.Device Represents an input device, such as a keyboard, mouse or touchpad.
  • Ocgdk.Device_tool A physical tool associated to a GdkDevice.
  • Ocgdk.Display A representation of a workstation.
  • Ocgdk.Display_manager Offers notification when displays appear or disappear.
  • Ocgdk.Dmabuf_texture A GdkTexture representing a DMA buffer.
  • Ocgdk.Dmabuf_texture_builder Constructs Gdk.Texture objects from DMA buffers.
  • Ocgdk.Dnd_event An event related to drag and drop operations.
  • Ocgdk.Drag Represents the source of an ongoing DND operation.
  • Ocgdk.Draw_context Base class for objects implementing different rendering methods.
  • Ocgdk.Drop Represents the target of an ongoing DND operation.
  • Ocgdk.Event Represents windowing system events.
  • Ocgdk.Focus_event An event related to a keyboard focus change.
  • Ocgdk.Frame_clock Tells the application when to update and repaint a surface.
  • Ocgdk.Gl_context Represents a platform-specific OpenGL draw context.
  • Ocgdk.Gl_texture A GdkTexture representing a GL texture object.
  • Ocgdk.Gl_texture_builder Constructs Gdk.Texture objects from GL textures.
  • Ocgdk.Grab_broken_event An event related to a broken windowing system grab.
  • Ocgdk.Key_event An event related to a key-based device.
  • Ocgdk.Memory_texture A GdkTexture representing image data in memory.
  • Ocgdk.Memory_texture_builder Constructs Gdk.Texture objects from system memory provided via GLib.Bytes.
  • Ocgdk.Monitor Represents the individual outputs that are associated with a GdkDisplay.
  • Ocgdk.Motion_event An event related to a pointer or touch device motion.
  • Ocgdk.Pad_event An event related to a pad-based device.
  • Ocgdk.Proximity_event An event related to the proximity of a tool to a device.
  • Ocgdk.Scroll_event An event related to a scrolling motion.
  • Ocgdk.Seat Represents a collection of input devices that belong to a user.
  • Ocgdk.Snapshot Base type for snapshot operations.
  • Ocgdk.Surface Represents a rectangular region on the screen.
  • Ocgdk.Texture Refers to pixel data in various forms.
  • Ocgdk.Touch_event An event related to a touch-based device.
  • Ocgdk.Touchpad_event An event related to a gesture on a touchpad device.
  • Ocgdk.Vulkan_context Represents the platform-specific Vulkan draw context.

Interfaces

  • Ocgdk.Device_pad An interface for tablet pad devices.
  • Ocgdk.Drag_surface A surface that is used during DND.
  • Ocgdk.Paintable An interface for content that can be painted.
  • Ocgdk.Popup A surface that is attached to another surface.
  • Ocgdk.Toplevel A freestanding toplevel surface.

Records

  • Ocgdk.Color_state Provides information to interpret colors and pixels in a variety of ways.
  • Ocgdk.Content_formats Used to advertise and negotiate the format of content.
  • Ocgdk.Content_formats_builder Creates GdkContentFormats objects.
  • Ocgdk.Dmabuf_formats Provides information about supported DMA buffer formats.
  • Ocgdk.Drag_surface_size Contains information that is useful to compute the size of a drag surface.
  • Ocgdk.Event_sequence An opaque type representing a sequence of related events.
  • Ocgdk.File_list An opaque type representing a list of files.
  • Ocgdk.Frame_timings Holds timing information for a single frame of the application’s displays.
  • Ocgdk.Keymap_key Represents a hardware key that can be mapped to a keyval.
  • Ocgdk.Popup_layout Contains information that is necessary position a Gdk.Popup relative to its parent.
  • Ocgdk.Rectangle Represents a rectangle.
  • Ocgdk.Rgb_a Represents a color, in a way that is compatible with cairo’s notion of color.
  • Ocgdk.Texture_downloader Used to download the contents of a Gdk.Texture.
  • Ocgdk.Time_coord Stores a single event in a motion history.
  • Ocgdk.Toplevel_layout Contains information that is necessary to present a sovereign window on screen.
  • Ocgdk.Toplevel_size Contains information that is useful to compute the size of a toplevel.
