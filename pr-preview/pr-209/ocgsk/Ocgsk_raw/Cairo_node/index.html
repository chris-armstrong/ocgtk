Module Ocgsk_raw.Cairo_node

A render node for a Cairo surface.

The class built on this module is in Ocgsk.Cairo_node.

val new_ : Ocgraphene_raw.Rect.t -> t

Creates a GskRenderNode that will render a cairo surface into the area given by bounds.

You can draw to the cairo surface using Gsk.CairoNode.get_draw_context.

val get_surface : t -> Occairo_raw.Surface.t

Retrieves the Cairo surface used by the render node.

val get_draw_context : t -> Occairo_raw.Context.t

Creates a Cairo context for drawing using the surface associated to the render node.

If no surface exists yet, a surface will be created optimized for rendering to renderer.
