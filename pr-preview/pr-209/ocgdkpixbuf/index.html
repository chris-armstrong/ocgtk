ocgdkpixbuf

The ocgdkpixbuf package provides OCaml bindings for GdkPixbuf: image loading, scaling and pixel-buffer manipulation. They are generated from GdkPixbuf's GObject introspection data.

  • Modules
  • Dependencies

Modules

The library is reached as Ocgdkpixbuf, with one module per class, interface or record, such as Ocgdkpixbuf.Pixbuf and Ocgdkpixbuf.Pixbuf_loader.

  • All modules — every class, interface and record, grouped by kind.
  • Ocgdkpixbuf.Enums — enumerations and bitfields.
  • Ocgdkpixbuf.Constants — constants.
  • Ocgdkpixbuf.Raw — the C externals and abstract types the modules above are built on.

Dependencies

It builds on Ocglib (GLib and GObject) and Ocgio.
