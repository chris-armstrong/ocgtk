class point : Ocgraphene.Raw.Point.t -> point_t

Wraps a layer 1 handle, Ocgraphene.Raw.Point.t. Apply it directly only to convert a handle obtained from layer 1: constructors, and methods that return a graphene_point_t, give one already wrapped.

Constructors

val alloc : unit -> point_t

Allocates a new #graphene_point_t structure.

The coordinates of the returned point are (0, 0).

It's possible to chain this function with graphene_point_init() or graphene_point_init_from_point(), e.g.:

  graphene_point_t *
  point_new (float x, float y)
  {
    return graphene_point_init (graphene_point_alloc (), x, y);
  }

  graphene_point_t *
  point_copy (const graphene_point_t *p)
  {
    return graphene_point_init_from_point (graphene_point_alloc (), p);
  }
