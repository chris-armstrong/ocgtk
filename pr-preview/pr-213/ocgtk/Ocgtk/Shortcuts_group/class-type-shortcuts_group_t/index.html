Class type Shortcuts_group.shortcuts_group_t

The methods, signals and properties of a ShortcutsGroup.

Inherits from: Ocgtk.Box

Implements:

  • Ocgtk.Accessible
  • Ocgtk.Buildable
  • Ocgtk.Constraint_target
  • Ocgtk.Orientable

A GtkShortcutsGroup represents a group of related keyboard shortcuts or gestures.

The group has a title. It may optionally be associated with a view of the application, which can be used to show only relevant shortcuts depending on the application context.

This widget is only meant to be used with Gtk.ShortcutsWindow.

The recommended way to construct a GtkShortcutsGroup is with Gtk.Builder, by using the <child> tag to populate a GtkShortcutsGroup with one or more Gtk.ShortcutsShortcut instances.

If you need to add a shortcut programmatically, use Gtk.ShortcutsGroup.add_shortcut.

Methods

method add_shortcut : Ocgtk.Shortcuts_shortcut.shortcuts_shortcut_t -> unit

Adds a shortcut to the shortcuts group.

This is the programmatic equivalent to using Gtk.Builder and a <child> tag to add the child. Adding children with other API is not appropriate as GtkShortcutsGroup manages its children internally.

method view : string

An optional view that the shortcuts in this group are relevant for.

The group will be hidden if the Gtk.ShortcutsWindow:view-name property does not match the view of this group.

Set this to NULL to make the group always visible.
