GdkPixbuf classes and records

Ocgdkpixbuf has one module for each GdkPixbuf class and record, with the externals they are built on in Ocgdkpixbuf.Raw, the enumerations and bitfields in Ocgdkpixbuf.Enums and the constants in Ocgdkpixbuf.Constants. See the conventions page for how the bindings are organised: the two layers, the anatomy of a class module, and how names, types, signals and properties are mapped.

  • Ocgdkpixbuf.Pixbuf_animation An opaque object representing an animation.
  • Ocgdkpixbuf.Pixbuf_animation_iter An opaque object representing an iterator which points to a certain position in an animation.

  • Ocgdkpixbuf.Pixbuf_simple_anim An opaque struct representing a simple animation.

Records

  • Ocgdkpixbuf.Pixbuf_format A GdkPixbufFormat contains information about the image format accepted by a module.
