Module Generate.Doc_index

val empty : Types.doc_index

Links to nothing: every reference stays code.

val build : namespace:string -> classes:Types.gir_class list -> interfaces:Types.gir_interface list -> records:Types.gir_record list -> enums:Types.gir_enum list -> bitfields:Types.gir_bitfield list -> constants:Types.gir_constant list -> cross_references: Types.generation_context_namespace_cross_references Types.StringMap.t -> Types.doc_index

The index for generating namespace, without the member tables of its classes, interfaces and records. Classes, records and constants are filtered by the same predicates the emitters use, so the lists may be the unfiltered ones.

val with_members : ctx:Types.generation_context -> Types.entity list -> Types.doc_index

ctx.doc_index with the member tables of entities, and their methods and constructors by C identifier. entities are the generated classes, interfaces and records of the current namespace. Deciding what an entity emits needs the generation context, so this is a second step.
