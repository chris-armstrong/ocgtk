Module Ocgio.Network_monitor

GNetworkMonitor provides an easy-to-use cross-platform API for monitoring network connectivity. On Linux, the available implementations are based on the kernel's netlink interface and on NetworkManager.

Its methods, signals and properties are on network_monitor_t. Its full description is under Description. Its constructors are under Constructors. The functions it is built on are in Ocgio.Raw.Network_monitor.
