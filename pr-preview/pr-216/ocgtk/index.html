ocgtk

The ocgtk package provides OCaml bindings for GTK 4: the widget toolkit, with windows, widgets, layout and the application model. They are generated from GTK's GObject introspection data, apart from Ocgtk.Main and Ocgtk.Version, which are hand-written.

The conventions page explains how the bindings are organised and how GObject maps onto OCaml.

Modules

The library is reached as Ocgtk, with one module per class, interface or record, such as Ocgtk.Window, Ocgtk.Button and Ocgtk.Application.

All classes, interfaces and records

  • Ocgtk.Main — initialising GTK and running the main loop.
  • Ocgtk.Version — the GTK version, at run time and at compile time.
  • Ocgtk.Enums — enumerations and bitfields.
  • Ocgtk.Constants — constants.
  • Ocgtk.Raw — the C externals and abstract types the modules above are built on.

Dependencies

GTK's supporting libraries are separate packages, each with its own index:

  • Ocglib — GLib and GObject.
  • Occairo — 2D vector graphics: drawing contexts, paths, patterns and surfaces.
  • Ocgdk — low-level windowing, displays, input and events that GTK is built on.
  • Ocgdkpixbuf — image loading, scaling and pixel-buffer manipulation.
  • Ocgio — I/O, files, and the application and networking abstractions from GLib's application framework.
  • Ocgraphene — lightweight 3D transform and geometry types (vectors, matrices, rectangles) used by Gsk and Gtk.
  • Ocgsk — the GTK scene graph: render nodes and transforms for drawing widgets.
  • Ocpango — text layout and internationalized font rendering.
  • Ocpangocairo — glue between Pango text layout and Cairo rendering.
