Class type Font_button.font_button_t

The methods, signals and properties of a FontButton.

Inherits from: Ocgtk.Widget

Implements:

  • Ocgtk.Accessible
  • Ocgtk.Buildable
  • Ocgtk.Constraint_target

The GtkFontButton allows to open a font chooser dialog to change the font.

An example GtkFontButton

It is suitable widget for selecting a font in a preference dialog.

Signals

method on_activate : ?after:bool -> callback:(unit -> unit) -> unit -> Ocglib.Gobject.Signal.handler_id

Emitted to when the font button is activated.

The ::activate signal on GtkFontButton is an action signal and emitting it causes the button to present its dialog.

method on_font_set : ?after:bool -> callback:(unit -> unit) -> unit -> Ocglib.Gobject.Signal.handler_id

Emitted when the user selects a font.

When handling this signal, use Gtk.FontChooser.get_font to find out which font was just selected.

Note that this signal is only emitted when the user changes the font. If you need to react to programmatic font changes as well, use the notify::font signal.
