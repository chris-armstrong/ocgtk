method on_interface_proxy_signal : ?after:bool -> callback: (object_proxy:Ocgio.D_bus_object_proxy.d_bus_object_proxy_t -> interface_proxy:Ocgio.D_bus_proxy.d_bus_proxy_t -> sender_name:string -> signal_name:string -> parameters:Ocglib.Gvariant.t -> unit) -> unit -> Ocglib.Gobject.Signal.handler_id

Emitted when a D-Bus signal is received on interface_proxy.

This signal exists purely as a convenience to avoid having to connect signals to all interface proxies managed by manager.

This signal is emitted in the thread-default main context (see GLib.MainContext.push_thread_default) that manager was constructed in.
