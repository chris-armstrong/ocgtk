ocgtk index

The ocgtk package provides OCaml bindings to GTK4 and its supporting libraries. Each namespace below is a separate sub-library; the .generated_stubs* libraries (pure C stubs with no OCaml modules, used internally to link the generated bindings) are omitted from this index.

Libraries

Ocgtk

The top-level module: re-exports every namespace below as a sub-module (e.g. Ocgtk.Gtk.Widget), plus Ocglib as Ocgtk.Common.

Ocgtk_cairo

2D vector graphics: drawing contexts, paths, patterns and surfaces.

Ocgtk_gdk

Low-level windowing, displays, input and events that Gtk is built on.

Ocgtk_gdkpixbuf

Image loading, scaling and pixel-buffer manipulation.

Ocgtk_gio

I/O, files, and the application/networking abstractions from GLib's application framework.

Ocgtk_graphene

Lightweight 3D transform and geometry types (vectors, matrices, rectangles) used by Gsk and Gtk.

Ocgtk_gsk

The GTK scene graph: render nodes and transforms for drawing widgets.

Ocgtk_gtk

The widget toolkit: windows, widgets, layout and the application model.

Ocgtk_pango

Text layout and internationalized font rendering.

Ocgtk_pangocairo

Glue between Pango text layout and Cairo rendering.

GLib and GObject (ocglib)

The hand-written GLib and GObject modules shared by every library above are in the separate ocglib package, as Ocglib.
