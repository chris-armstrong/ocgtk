Class Tree_path.tree_path

Wraps a raw handle of Ocgtk.Raw.Tree_path.t.

  • Methods

Methods

method append_index : int -> unit

Appends a new index to a path.

As a result, the depth of the path is increased.

method compare : Ocgtk.Raw.Tree_path.t -> int

Compares two paths.

If a appears before b in a tree, then -1 is returned. If b appears before a, then 1 is returned. If the two nodes are equal, then 0 is returned.

method down : unit -> unit

Moves path to point to the first child of the current path.

method get_depth : unit -> int

Returns the current depth of path.

method is_ancestor : Ocgtk.Raw.Tree_path.t -> bool

Returns true if descendant is a descendant of path.

method is_descendant : Ocgtk.Raw.Tree_path.t -> bool

Returns true if path is a descendant of ancestor.

method next : unit -> unit

Moves the path to point to the next node at the current depth.

method prepend_index : int -> unit

Prepends a new index to a path.

As a result, the depth of the path is increased.

method prev : unit -> bool

Moves the path to point to the previous node at the current depth, if it exists.

method to_string : unit -> string option

Generates a string representation of the path.

This string is a “:” separated list of numbers. For example, “4:10:0:3” would be an acceptable return value for this string. If the path has depth 0, None is returned.

method up : unit -> bool

Moves the path to point to its parent node, if it has a parent.
