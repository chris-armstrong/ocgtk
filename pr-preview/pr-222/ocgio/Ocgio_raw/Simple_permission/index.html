Module Ocgio_raw.Simple_permission

GSimplePermission is a trivial implementation of Gio.Permission that represents a permission that is either always or never allowed. The value is given at construction and doesn’t change.

Calling Gio.Permission.acquire or Gio.Permission.release on a GSimplePermission will result in errors.
