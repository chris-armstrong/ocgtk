Module Ocgio.Proxy

A GProxy handles connecting to a remote host via a given type of proxy server. It is implemented by the gio-proxy extension point. The extensions are named after their proxy protocol name. As an example, a SOCKS5 proxy implementation can be retrieved with the name socks5 using the function Gio.IOExtensionPoint.get_extension_by_name.

Its methods, signals and properties are on proxy_t. Its constructors are under Constructors. The functions it is built on are in Ocgio.Raw.Proxy.
