Forward declaration helper - generate a section of forward declarations. Common pattern across record, class, enum, and bitfield modules.

Parameters:

  • buf: Buffer to append declarations to
  • items: List of items to generate declarations for
  • section_comment: Comment header for this section
  • generate_one: Function to generate declarations for a single item
  • deduplicate: Whether to track seen types with Hashtbl (default: true)

val generate_multi_param_function : ml_name:string -> params:string list -> param_names:string list -> string -> string

generate_multi_param_function ~ml_name ~params ~param_names body_code generates both native and bytecode C wrapper variants for functions with more than 5 parameters (native uses CAMLparam5 + CAMLxparamN chunks; bytecode forwards argv to the native variant). Shared by the method and constructor C-stub generators to avoid the byte-for-byte duplication that previously lived in both modules.
