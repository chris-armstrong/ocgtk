val cross_ns_class_provides_interface : ctx:Types.generation_context -> depth:int -> ns:string -> string -> Stdlib.StdLabels.String.t -> bool

Check whether a cross-namespace class (by "Namespace.Name") or any of its ancestors provides iface_name. Traverses same-namespace parents within the foreign namespace by qualifying them with the current namespace. Depth-limited to 100 to avoid loops on malformed data.

val parent_chain_provides_interface : ctx:Types.generation_context -> class_name:Stdlib.StdLabels.String.t -> Stdlib.StdLabels.String.t -> bool

Return true if any class in the transitive parent chain of class_name lists iface_name in its implements. Used to detect diamond interface inheritance so the child can skip re-emitting an interface already provided by a parent, avoiding OCaml warning 7 (method-override).

Traverses cross-namespace parents via the cross-references map when the parent name contains a dot (e.g. "Gio.Application").
