ocgsk

The ocgsk package provides OCaml bindings for GSK 4, the GTK scene graph: render nodes and transforms for drawing widgets. They are generated from GSK's GObject introspection data.

  • Modules
  • Dependencies

Modules

The library is reached as Ocgsk, with one module per class, interface or record, such as Ocgsk.Render_node and Ocgsk.Transform.

  • Ocgsk.Enums — enumerations and bitfields.
  • Ocgsk.Raw — the C externals and abstract types the modules above are built on.

Dependencies

It builds on Ocglib (GLib and GObject), Occairo, Ocgdk, Ocgdkpixbuf, Ocgio, Ocgraphene, Ocpango and Ocpangocairo.
