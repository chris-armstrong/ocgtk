Module Wrappers.Color_chooser_dialog

A dialog for choosing a color.

An example GtkColorChooserDialog

GtkColorChooserDialog implements the Gtk.ColorChooser interface and does not provide much API of its own.

To create a GtkColorChooserDialog, use Gtk.ColorChooserDialog.new.

To change the initially selected color, use Gtk.ColorChooser.set_rgba. To get the selected color use Gtk.ColorChooser.get_rgba.

GtkColorChooserDialog has been deprecated in favor of Gtk.ColorDialog.

CSS nodes

GtkColorChooserDialog has a single CSS node with the name window and style class .colorchooser.
