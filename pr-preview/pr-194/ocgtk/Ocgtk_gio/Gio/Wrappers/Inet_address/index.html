Module Wrappers.Inet_address

GInetAddress represents an IPv4 or IPv6 internet address. Use Gio.Resolver.lookup_by_name or Gio.Resolver.lookup_by_name_async to look up the GInetAddress for a hostname. Use Gio.Resolver.lookup_by_address or Gio.Resolver.lookup_by_address_async to look up the hostname for a GInetAddress.

To actually connect to a remote host, you will need a Gio.InetSocketAddress (which includes a GInetAddress as well as a port number).
