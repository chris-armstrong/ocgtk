Module Ocgtk_gio.Gio_volume_monitor_core

Hand-written binding for the GVolumeMonitor singleton getter.

g_volume_monitor_get() is a free function (not a GIR class constructor), so the generator does not produce it. This module provides the C FFI stub so that L1/L2 code can obtain the singleton Volume_monitor instance.

val volume_monitor_get : unit -> [ `volume_monitor | `object_ ] Gobject.obj

Get the singleton GVolumeMonitor.

  • returns

    The global Volume_monitor.t instance, or raises if GTK/GIO has not been initialised.
