The two layers

TODO: cover

  • Layer 1 (the Wrappers modules): one module per class, an abstract handle type t, one function per C function. Closest to the C API.
  • Layer 2 (the class modules): one module per class, holding an OCaml class type, a class, and constructors. Methods, signals and properties are object methods. This is the layer most code should use.
  • Both layers wrap the same objects; you can move between them (see Converting between the layers).
  • When to use Layer 1: interop, functions with no Layer 2 form, or avoiding objects in performance-sensitive code (check that this claim holds before writing it).

Anatomy of a class module

TODO: walk through one class end to end (suggest Gtk.Button: small, has several constructors, a signal, an interface).

  • class type button_t: the object's methods, signals and properties. Grouped on its page into Signals, Methods, Properties and Conversions.
  • class button: wraps an existing Layer 1 handle. Not normally called directly; use the constructors.
  • new_, new_with_label, ...: the constructors. They return button_t.
  • Why the class type is button_t and not t: types in signatures and error messages read as Button.button_t, not an anonymous t.

Creating objects

TODO: cover the four cases each class page states in its canned text.

  • The class has constructors: call one (Button.new_with_label "OK").
  • Abstract class: no constructor; create a subclass instead (for example Widget).
  • Interface: no constructor; values come from methods or functions, or from objects that implement it.
  • Neither: the object is returned by methods on other classes (for example a Display, a Clipboard, an event).

Inheritance and interfaces

TODO: cover

  • How the C hierarchy maps onto class types: a class type inherits its parent's class type and the class types of the interfaces it implements. Each class type page lists "Inherits from" and "Implements".
  • Upcasting with :> (for example (button :> Widget.widget_t)).
  • Downcasting / runtime type checks: say what is and is not supported (check the current API before writing).
  • as_* methods return the Layer 1 handle.
  • Cyclic groups: some modules have long generated names such as GEvent_controller_and__..._widget. These are internal; use the public module (Gtk.Widget).
