Class type Bitset_iter.bitset_iter_t

The methods, signals and properties of a BitsetIter.

Iterates over the elements of a Gtk.Bitset.

`GtkBitSetIter is an opaque, stack-allocated struct.

Before a GtkBitsetIter can be used, it needs to be initialized with Gtk.BitsetIter.init_first, Gtk.BitsetIter.init_last or Gtk.BitsetIter.init_at.
