Class type Cairo_context.cairo_context_t

The methods, signals and properties of a CairoContext.

Inherits from: Ocgdk.Draw_context

Represents the platform-specific draw context.

GdkCairoContexts are created for a surface using Gdk.Surface.create_cairo_context, and the context can then be used to draw on that surface.

  • Methods
  • Conversions

Methods

method cairo_create : unit -> Occairo.Context.context_t option

Retrieves a Cairo context to be used to draw on the GdkSurface of context.

A call to Gdk.DrawContext.begin_frame with this context must have been done or this function will return NULL.

The returned context is guaranteed to be valid until Gdk.DrawContext.end_frame is called.
