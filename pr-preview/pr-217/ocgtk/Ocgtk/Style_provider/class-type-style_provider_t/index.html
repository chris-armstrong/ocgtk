Class type Style_provider.style_provider_t

The methods, signals and properties of a StyleProvider.

An interface for style information used by Gtk.StyleContext.

See Gtk.StyleContext.add_provider and Gtk.StyleContext.add_provider_for_display for adding GtkStyleProviders.

GTK uses the GtkStyleProvider implementation for CSS in Gtk.CssProvider.
