Class type Cell_renderer_accel.cell_renderer_accel_t

The methods, signals and properties of a CellRendererAccel.

Inherits from: Ocgtk.Cell_renderer_text

Renders a keyboard accelerator in a cell

GtkCellRendererAccel displays a keyboard accelerator (i.e. a key combination like Control + a). If the cell renderer is editable, the accelerator can be changed by simply typing the new combination.

method accel_mode : Ocgtk.Enums.cellrendereraccelmode

Determines if the edited accelerators are GTK accelerators. If they are, consumed modifiers are suppressed, only accelerators accepted by GTK are allowed, and the accelerators are rendered in the same way as they are in menus.
