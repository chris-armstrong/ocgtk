Module Ocgio.Tls_file_database

GTlsFileDatabase is implemented by Gio.TlsDatabase objects which load their certificate information from a file. It is an interface which TLS library specific subtypes implement.

Its methods, signals and properties are on tls_file_database_t. Its constructors are under Constructors. The functions it is built on are in Ocgio.Raw.Tls_file_database.
