Module Generate.Doc_resolve

type env = {
  1. namespace : string;
    (*

    The namespace the doc belongs to.

    *)
  2. layer : Types.target_library;
    (*

    The library the doc is emitted into: Raw_library for layer 1.

    *)
  3. index : Types.doc_index;
}
val env_of_ctx : Types.generation_context -> env

The namespace, target library and index of the context. Enumeration, bitfield and constant docs are shared by both layers and pass the Main_library context.

val no_links : namespace:string -> env

An empty index: every reference stays code. For callers with no generation context, such as unit tests.

val class_member : env -> env

env for the doc of a method, signal or property accessor inside a class or class type: it links nothing. odoc 3.2 resolves no reference in the doc of a class or class type member: it renders each as unresolved text, without a warning. The class type's own doc links as usual.

type miss_reason =
  1. | Namespace_not_generated
    (*

    The endpoint's namespace is not in the index: not generated (GLib, GObject), or not a dependency of the doc's namespace.

    *)
  2. | Unknown_target
    (*

    The namespace is indexed but does not generate the target.

    *)
  3. | Member_in_other_namespace
    (*

    A member of a type of another namespace: only members of the current namespace can be checked.

    *)
  4. | Kind_not_generated
    (*

    Functions, callbacks, virtual functions, aliases and error domains: never generated.

    *)
  5. | Not_resolved_yet
    (*

    Members, legacy sigils and C symbols.

    *)

Why a reference stays code.

val equal_miss_reason : miss_reason -> miss_reason -> Ppx_deriving_runtime.bool
val miss_reason_name : miss_reason -> string

Name in the summary: "unknown-target", ...

type outcome = {
  1. kind : Doc_ast.sym_kind option;
    (*

    The fragment keyword; None for a legacy sigil.

    *)
  2. endpoint : string;
  3. result : (unit, miss_reason) Stdlib.result;
    (*

    Ok () when linked.

    *)
}
val resolve : env -> Doc_ast.t -> Doc_ast.t * outcome list

resolve env doc links the references of doc the index can satisfy, and returns one outcome per Sym_ref, in document order.

val pp_summary : outcome list Fmt.t

Counts of linked references and of each miss reason per fragment kind, then every distinct endpoint that missed with Unknown_target.
