Class Key_event.key_event

Wraps a layer 1 handle, Ocgdk.Raw.Key_event.t. Apply it directly only to convert a handle obtained from layer 1: constructors, and methods that return a GdkKeyEvent, give one already wrapped.

method matches : int -> Ocgdk.Enums.modifiertype -> Ocgdk.Enums.keymatch

Matches a key event against a keyval and modifiers.

This is typically used to trigger keyboard shortcuts such as Ctrl-C.

Partial matches are possible where the combination matches if the currently active group is ignored.

Note that we ignore Caps Lock for matching.
