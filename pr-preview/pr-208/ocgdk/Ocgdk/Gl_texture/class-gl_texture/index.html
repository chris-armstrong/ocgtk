Class Gl_texture.gl_texture

Wraps a layer 1 handle, Ocgdk.Raw.Gl_texture.t. Apply it directly only to convert a handle obtained from layer 1: constructors, and methods that return a GdkGLTexture, give one already wrapped.

inherit Ocgdk.Texture.texture_t
method release : unit -> unit

Releases the GL resources held by a GdkGLTexture.

The texture contents are still available via the Gdk.Texture.download function, after this function has been called.
