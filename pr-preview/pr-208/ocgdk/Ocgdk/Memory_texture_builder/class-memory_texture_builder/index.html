Class Memory_texture_builder.memory_texture_builder

Wraps a layer 1 handle, Ocgdk.Raw.Memory_texture_builder.t. Apply it directly only to convert a handle obtained from layer 1: constructors, and methods that return a GdkMemoryTextureBuilder, give one already wrapped.

method build : unit -> Ocgdk.Texture.texture_t

Builds a new GdkTexture with the values set up in the builder.

Note that it is a programming error to call this function if any mandatory property has not been set.

It is possible to call this function multiple times to create multiple textures, possibly with changing properties in between.

method set_bytes : Ocglib.Glib_bytes.t option -> unit

Sets the data to be shown but the texture.

The bytes must be set before calling Gdk.MemoryTextureBuilder.build.

method set_color_state : Ocgdk.Raw.Color_state.t -> unit

Sets the colorstate describing the data.

By default, the sRGB colorstate is used. If you don't know what colorstates are, this is probably the right thing.

method set_format : Ocgdk.Enums.memoryformat -> unit

Sets the format of the bytes.

The default is GDK_MEMORY_R8G8B8A8_PREMULTIPLIED.

method set_height : int -> unit

Sets the height of the texture.

The height must be set before calling Gdk.MemoryTextureBuilder.build and conform to size requirements of the provided format.

method set_offset : int -> Ocglib.Gsize.t -> unit

Sets the offset of the texture for plane.

method set_stride : Ocglib.Gsize.t -> unit

Sets the rowstride of the bytes used.

The rowstride must be set before calling Gdk.MemoryTextureBuilder.build.

method set_stride_for_plane : int -> Ocglib.Gsize.t -> unit

Sets the stride of the texture for plane.

method set_update_region : Occairo.Region.region_t option -> unit

Sets the region to be updated by this texture.

Together with Gdk.MemoryTextureBuilder:update-texture, this describes an update of a previous texture.

When rendering animations of large textures, it is possible that consecutive textures are only updating contents in parts of the texture. It is then possible to describe this update via these two properties, so that GTK can avoid rerendering parts that did not change.

An example would be a screen recording where only the mouse pointer moves.

method set_update_texture : Ocgdk.Texture.texture_t option -> unit

Sets the texture to be updated by this texture.

See Gdk.MemoryTextureBuilder.set_update_region for an explanation.
