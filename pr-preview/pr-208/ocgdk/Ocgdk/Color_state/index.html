Module Ocgdk.Color_state

Provides information to interpret colors and pixels in a variety of ways.

They are also known as color spaces.

Crucially, GTK knows how to convert colors from one color state to another.

GdkColorState objects are immutable and therefore threadsafe.

Its methods, signals and properties are on color_state_t. The functions it is built on are in Ocgdk.Raw.Color_state.

class type color_state_t = Ocgdk.Cicp_params_and__color_state.color_state_t

The methods, signals and properties of a GdkColorState.

class color_state : Ocgdk.Raw.Color_state.t -> color_state_t

Wraps a layer 1 handle, Ocgdk.Raw.Color_state.t. Apply it directly only to convert a handle obtained from layer 1: constructors, and methods that return a GdkColorState, give one already wrapped.
