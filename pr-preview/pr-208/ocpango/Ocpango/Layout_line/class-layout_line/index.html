Class Layout_line.layout_line

Wraps a layer 1 handle, Ocpango.Raw.Layout_line.t. Apply it directly only to convert a handle obtained from layer 1: constructors, and methods that return a PangoLayoutLine, give one already wrapped.

method get_length : unit -> int

Returns the length of the line, in bytes.

method get_resolved_direction : unit -> Ocpango.Enums.direction

Returns the resolved direction of the line.

method get_start_index : unit -> int

Returns the start index of the line, as byte index into the text of the layout.

method is_paragraph_start : unit -> bool

Returns whether this is the first line of the paragraph.

Increase the reference count of a PangoLayoutLine by one.
