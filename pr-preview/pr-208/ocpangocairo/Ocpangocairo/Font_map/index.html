Module Ocpangocairo.Font_map

PangoCairoFontMap is an interface exported by font maps for use with Cairo.

The actual type of the font map will depend on the particular font technology Cairo was compiled to use.

Its methods, signals and properties are on font_map_t. The functions it is built on are in Ocpangocairo.Raw.Font_map.

class type font_map_t = object ... end

The methods, signals and properties of a PangoCairoFontMap.

class font_map : Ocpangocairo.Raw.Font_map.t -> font_map_t

Wraps a layer 1 handle, Ocpangocairo.Raw.Font_map.t. Apply it directly only to convert a handle obtained from layer 1: constructors, and methods that return a PangoCairoFontMap, give one already wrapped.
