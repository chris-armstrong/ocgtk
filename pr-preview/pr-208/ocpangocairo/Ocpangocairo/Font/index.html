Module Ocpangocairo.Font

PangoCairoFont is an interface exported by fonts for use with Cairo.

The actual type of the font will depend on the particular font technology Cairo was compiled to use.

Its methods, signals and properties are on font_t. The functions it is built on are in Ocpangocairo.Raw.Font.

class type font_t = object ... end

The methods, signals and properties of a PangoCairoFont.

class font : Ocpangocairo.Raw.Font.t -> font_t

Wraps a layer 1 handle, Ocpangocairo.Raw.Font.t. Apply it directly only to convert a handle obtained from layer 1: constructors, and methods that return a PangoCairoFont, give one already wrapped.
