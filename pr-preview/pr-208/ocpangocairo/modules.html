PangoCairo modules

Ocpangocairo has one module for each PangoCairo class, interface and record. The externals they are built on are in Ocpangocairo.Raw.

  • Interfaces

Interfaces

  • Ocpangocairo.Font PangoCairoFont is an interface exported by fonts for use with Cairo.
  • Ocpangocairo.Font_map PangoCairoFontMap is an interface exported by font maps for use with Cairo.
