Module Ocgtk.C_closure_expression

A variant of GtkClosureExpression using a C closure.

Its methods, signals and properties are on c_closure_expression_t. The functions it is built on are in Ocgtk.Raw.C_closure_expression.

class c_closure_expression : Ocgtk.Raw.C_closure_expression.t -> c_closure_expression_t
