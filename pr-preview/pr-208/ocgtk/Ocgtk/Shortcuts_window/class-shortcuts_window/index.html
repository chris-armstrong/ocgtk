Class Shortcuts_window.shortcuts_window

Wraps a layer 1 handle, Ocgtk.Raw.Shortcuts_window.t. Apply it directly only to convert a handle obtained from layer 1: constructors, and methods that return a GtkShortcutsWindow, give one already wrapped.

inherit Ocgtk.Application_and__window_and__window_group.window_t
method on_close : ?after:bool -> callback:(unit -> unit) -> unit -> Ocglib.Gobject.Signal.handler_id

Emitted when the user uses a keybinding to close the window.

This is a keybinding signal.

The default binding for this signal is the <kbd>Escape</kbd> key.

method on_search : ?after:bool -> callback:(unit -> unit) -> unit -> Ocglib.Gobject.Signal.handler_id

Emitted when the user uses a keybinding to start a search.

This is a keybinding signal.

The default binding for this signal is <kbd>Control</kbd>+<kbd>F</kbd>.

method add_section : Ocgtk.Shortcuts_section.shortcuts_section_t -> unit

Adds a section to the shortcuts window.

This is the programmatic equivalent to using Gtk.Builder and a <child> tag to add the child.

Using Gtk.Window.set_child is not appropriate as the shortcuts window manages its children internally.
