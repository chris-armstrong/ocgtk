Module Ocgtk.Text_buffer

Stores text and attributes for display in a GtkTextView.

You may wish to begin by reading the text widget conceptual overview, which gives an overview of all the objects and data types related to the text widget and how they work together.

GtkTextBuffer can support undoing changes to the buffer content, see Gtk.TextBuffer.set_enable_undo.

Its methods, signals and properties are on text_buffer_t. Its constructors are under Constructors. The functions it is built on are in Ocgtk.Raw.Text_buffer.
