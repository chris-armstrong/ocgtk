Module Ocgtk.Shortcuts_shortcut

A GtkShortcutsShortcut represents a single keyboard shortcut or gesture with a short text.

This widget is only meant to be used with GtkShortcutsWindow.

Its methods, signals and properties are on shortcuts_shortcut_t. The functions it is built on are in Ocgtk.Raw.Shortcuts_shortcut.
