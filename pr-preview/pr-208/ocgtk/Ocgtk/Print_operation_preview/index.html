Module Ocgtk.Print_operation_preview

The interface that is used to implement print preview.

A GtkPrintOperationPreview object is passed to the Gtk.PrintOperation::preview signal by Gtk.PrintOperation.

Its methods, signals and properties are on print_operation_preview_t. The functions it is built on are in Ocgtk.Raw.Print_operation_preview.

class type print_operation_preview_t = object ... end

The methods, signals and properties of a GtkPrintOperationPreview.

class print_operation_preview : Ocgtk.Raw.Print_operation_preview.t -> print_operation_preview_t

Wraps a layer 1 handle, Ocgtk.Raw.Print_operation_preview.t. Apply it directly only to convert a handle obtained from layer 1: constructors, and methods that return a GtkPrintOperationPreview, give one already wrapped.
