Module Ocgtk.Css_section

Defines a part of a CSS document.

Because sections are nested into one another, you can use CssSection.get_parent to get the containing region.

Its methods, signals and properties are on css_section_t. Its constructors are under Constructors. The functions it is built on are in Ocgtk.Raw.Css_section.
