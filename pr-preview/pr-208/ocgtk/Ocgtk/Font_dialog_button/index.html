Module Ocgtk.Font_dialog_button

Opens a font chooser dialog to select a font.

An example GtkFontDialogButton

It is suitable widget for selecting a font in a preference dialog.

CSS nodes

fontbutton
╰── button.font
    ╰── [content]

GtkFontDialogButton has a single CSS node with name fontbutton which contains a button node with the .font style class.

Its methods, signals and properties are on font_dialog_button_t. Its constructors are under Constructors. The functions it is built on are in Ocgtk.Raw.Font_dialog_button.

class font_dialog_button : Ocgtk.Raw.Font_dialog_button.t -> font_dialog_button_t

Wraps a layer 1 handle, Ocgtk.Raw.Font_dialog_button.t. Apply it directly only to convert a handle obtained from layer 1: constructors, and methods that return a GtkFontDialogButton, give one already wrapped.

Constructors

val new_ : Font_dialog.font_dialog_t option -> font_dialog_button_t

Creates a new GtkFontDialogButton with the given GtkFontDialog.

You can pass NULL to this function and set a GtkFontDialog later. The button will be insensitive until that happens.
