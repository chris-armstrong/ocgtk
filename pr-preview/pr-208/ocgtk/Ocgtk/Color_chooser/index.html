Module Ocgtk.Color_chooser

GtkColorChooser is an interface that is implemented by widgets for choosing colors.

Depending on the situation, colors may be allowed to have alpha (translucency).

In GTK, the main widgets that implement this interface are Gtk.ColorChooserWidget, Gtk.ColorChooserDialog and Gtk.ColorButton.

Its methods, signals and properties are on color_chooser_t. The functions it is built on are in Ocgtk.Raw.Color_chooser.
