Class Text_tag_table.text_tag_table

Wraps a layer 1 handle, Ocgtk.Raw.Text_tag_table.t. Apply it directly only to convert a handle obtained from layer 1: constructors, and methods that return a GtkTextTagTable, give one already wrapped.

method on_tag_removed : ?after:bool -> callback:(tag:Ocgtk.Text_tag.text_tag_t -> unit) -> unit -> Ocglib.Gobject.Signal.handler_id

Emitted every time a tag is removed from the GtkTextTagTable.

The tag is still valid by the time the signal is emitted, but it is not associated with a tag table any more.

method add : Ocgtk.Text_tag.text_tag_t -> bool

Add a tag to the table.

The tag is assigned the highest priority in the table.

tag must not be in a tag table already, and may not have the same name as an already-added tag.

method get_size : unit -> int

Returns the size of the table (number of tags)

method lookup : string -> Ocgtk.Text_tag.text_tag_t option

Look up a named tag.

method remove : Ocgtk.Text_tag.text_tag_t -> unit

Remove a tag from the table.

If a GtkTextBuffer has table as its tag table, the tag is removed from the buffer. The table’s reference to the tag is removed, so the tag will end up destroyed if you don’t have a reference to it.
