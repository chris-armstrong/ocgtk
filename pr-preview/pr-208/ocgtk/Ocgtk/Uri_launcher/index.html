Module Ocgtk.Uri_launcher

Asynchronous API to open a uri with an application.

GtkUriLauncher collects the arguments that are needed to open the uri.

Depending on system configuration, user preferences and available APIs, this may or may not show an app chooser dialog or launch the default application right away.

The operation is started with the Gtk.UriLauncher.launch function.

To launch a file, use Gtk.FileLauncher.

Its methods, signals and properties are on uri_launcher_t. Its constructors are under Constructors. The functions it is built on are in Ocgtk.Raw.Uri_launcher.
