Class Uri_launcher.uri_launcher

Wraps a layer 1 handle, Ocgtk.Raw.Uri_launcher.t. Apply it directly only to convert a handle obtained from layer 1: constructors, and methods that return a GtkUriLauncher, give one already wrapped.

method can_launch : Ocgtk.Application_and__window_and__window_group.window_t option -> bool

Returns whether the launcher is likely to succeed in launching an application for its uri.

This can be used to disable controls that trigger the launcher when they are known not to work.
