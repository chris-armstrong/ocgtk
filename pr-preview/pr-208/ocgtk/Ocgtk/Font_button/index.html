Module Ocgtk.Font_button

The GtkFontButton allows to open a font chooser dialog to change the font.

An example GtkFontButton

It is suitable widget for selecting a font in a preference dialog.

CSS nodes

fontbutton
╰── button.font
    ╰── [content]

GtkFontButton has a single CSS node with name fontbutton which contains a button node with the .font style class.

Its methods, signals and properties are on font_button_t. Its constructors are under Constructors. The functions it is built on are in Ocgtk.Raw.Font_button.
