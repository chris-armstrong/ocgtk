Module Ocgtk.Requested_size

Represents a request of a screen object in a given orientation.

These are primarily used in container implementations when allocating a natural size for children. See distribute_natural_allocation.

Its methods, signals and properties are on requested_size_t. The functions it is built on are in Ocgtk.Raw.Requested_size.
