Module Ocgtk.Style_provider

An interface for style information used by Gtk.StyleContext.

See Gtk.StyleContext.add_provider and Gtk.StyleContext.add_provider_for_display for adding GtkStyleProviders.

GTK uses the GtkStyleProvider implementation for CSS in Gtk.CssProvider.

Its methods, signals and properties are on style_provider_t. The functions it is built on are in Ocgtk.Raw.Style_provider.

The methods, signals and properties of a GtkStyleProvider.

class style_provider : Ocgtk.Raw.Style_provider.t -> style_provider_t

Wraps a layer 1 handle, Ocgtk.Raw.Style_provider.t. Apply it directly only to convert a handle obtained from layer 1: constructors, and methods that return a GtkStyleProvider, give one already wrapped.
