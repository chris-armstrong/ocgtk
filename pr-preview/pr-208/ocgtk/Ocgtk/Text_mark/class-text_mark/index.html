Class Text_mark.text_mark

Wraps a layer 1 handle, Ocgtk.Raw.Text_mark.t. Apply it directly only to convert a handle obtained from layer 1: constructors, and methods that return a GtkTextMark, give one already wrapped.

method get_buffer : unit -> Ocgtk.Text_buffer_and__text_iter_and__text_mark.text_buffer_t option

Gets the buffer this mark is located inside.

Returns NULL if the mark is deleted.

method get_deleted : unit -> bool

Returns TRUE if the mark has been removed from its buffer.

See Gtk.TextBuffer.add_mark for a way to add it to a buffer again.

method get_left_gravity : unit -> bool

Determines whether the mark has left gravity.

method get_name : unit -> string option

Returns the mark name.

Returns NULL for anonymous marks.

method get_visible : unit -> bool

Returns TRUE if the mark is visible.

A cursor is displayed for visible marks.

method set_visible : bool -> unit

Sets the visibility of mark.

The insertion point is normally visible, i.e. you can see it as a vertical bar. Also, the text widget uses a visible mark to indicate where a drop will occur when dragging-and-dropping text. Most other marks are not visible.

Marks are not visible by default.
