Class type Event_controller.event_controller_t

The methods, signals and properties of a GtkEventController.

method get_current_event : unit -> Ocgdk.Event.event_t option

Returns the event that is currently being handled by the controller.

At other times, NULL is returned.

method get_current_event_device : unit -> Ocgdk.Device.device_t option

Returns the device of the event that is currently being handled by the controller.

At other times, NULL is returned.

method get_current_event_state : unit -> Ocgdk.Enums.modifiertype

Returns the modifier state of the event that is currently being handled by the controller.

At other times, 0 is returned.

method get_current_event_time : unit -> Ocglib.UInt32.t

Returns the timestamp of the event that is currently being handled by the controller.

At other times, 0 is returned.

method get_name : unit -> string option

Gets the name of controller.

method get_propagation_limit : unit -> Ocgtk.Enums.propagationlimit

Gets the propagation limit of the event controller.

method get_propagation_phase : unit -> Ocgtk.Enums.propagationphase

Gets the propagation phase at which controller handles events.

method get_widget : unit -> Ocgtk.Event_controller_and__layout_child_and__layout_manager_and__root_and__tooltip_and__widget.widget_t option

Returns the GtkWidget this controller relates to.

method reset : unit -> unit

Resets the controller to a clean state.

method set_name : string option -> unit

Sets a name on the controller that can be used for debugging.

method set_propagation_limit : Ocgtk.Enums.propagationlimit -> unit

Sets the event propagation limit on the event controller.

If the limit is set to GTK_LIMIT_SAME_NATIVE, the controller won't handle events that are targeted at widgets on a different surface, such as popovers.

method set_propagation_phase : Ocgtk.Enums.propagationphase -> unit

Sets the propagation phase at which a controller handles events.

If phase is GTK_PHASE_NONE, no automatic event handling will be performed, but other additional gesture maintenance will.

method set_static_name : string option -> unit

Sets a name on the controller that can be used for debugging.
