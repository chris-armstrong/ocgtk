Module Ocgtk.Constraint_target

Makes it possible to use an object as source or target in a Gtk.Constraint.

Besides GtkWidget, it is also implemented by GtkConstraintGuide.

Its methods, signals and properties are on constraint_target_t. The functions it is built on are in Ocgtk.Raw.Constraint_target.
