Class Path_measure.path_measure

Wraps a layer 1 handle, Ocgsk.Raw.Path_measure.t. Apply it directly only to convert a handle obtained from layer 1: constructors, and methods that return a GskPathMeasure, give one already wrapped.

method get_length : unit -> float

Gets the length of the path being measured.

The length is cached, so this function does not do any work.

method get_path : unit -> Ocgsk.Raw.Path.t

Returns the path that the measure was created for.

method get_tolerance : unit -> float

Returns the tolerance that the measure was created with.

method ref : unit -> Ocgsk.Raw.Path_measure.t

Increases the reference count of a GskPathMeasure by one.
