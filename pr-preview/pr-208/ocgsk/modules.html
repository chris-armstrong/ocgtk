Gsk modules

Ocgsk has one module for each Gsk class, interface and record. The externals they are built on are in Ocgsk.Raw.

  • Classes
  • Records

Classes

  • Ocgsk.Blend_node A render node applying a blending function between its two child nodes.
  • Ocgsk.Blur_node A render node applying a blur effect to its single child.
  • Ocgsk.Border_node A render node for a border.
  • Ocgsk.Cairo_node A render node for a Cairo surface.
  • Ocgsk.Cairo_renderer Renders a GSK rendernode tree with cairo.
  • Ocgsk.Clip_node A render node applying a rectangular clip to its single child node.
  • Ocgsk.Color_matrix_node A render node controlling the color matrix of its single child node.
  • Ocgsk.Color_node A render node for a solid color.
  • Ocgsk.Component_transfer_node Bindings for GskComponentTransferNode.
  • Ocgsk.Conic_gradient_node A render node for a conic gradient.
  • Ocgsk.Container_node A render node that can contain other render nodes.
  • Ocgsk.Cross_fade_node A render node cross fading between two child nodes.
  • Ocgsk.Debug_node A render node that emits a debugging message when drawing its child node.
  • Ocgsk.Fill_node A render node filling the area given by Gsk.Path and Gsk.FillRule with the child node.
  • Ocgsk.Gl_shader Implements a fragment shader using GLSL.
  • Ocgsk.Gl_shader_node A render node using a GL shader when drawing its children nodes.
  • Ocgsk.Inset_shadow_node A render node for an inset shadow.
  • Ocgsk.Linear_gradient_node A render node for a linear gradient.
  • Ocgsk.Mask_node A render node masking one child node with another.
  • Ocgsk.Opacity_node A render node controlling the opacity of its single child node.
  • Ocgsk.Outset_shadow_node A render node for an outset shadow.
  • Ocgsk.Radial_gradient_node A render node for a radial gradient.
  • Ocgsk.Render_node The basic block in a scene graph to be rendered using Gsk.Renderer.
  • Ocgsk.Renderer Renders a scene graph defined via a tree of Gsk.RenderNode instances.
  • Ocgsk.Repeat_node A render node repeating its single child node.
  • Ocgsk.Repeating_linear_gradient_node A render node for a repeating linear gradient.
  • Ocgsk.Repeating_radial_gradient_node A render node for a repeating radial gradient.
  • Ocgsk.Rounded_clip_node A render node applying a rounded rectangle clip to its single child.
  • Ocgsk.Shadow_node A render node drawing one or more shadows behind its single child node.
  • Ocgsk.Stroke_node A render node that will fill the area determined by stroking the the given Gsk.Path using the Gsk.Stroke attributes.
  • Ocgsk.Subsurface_node A render node that potentially diverts a part of the scene graph to a subsurface.
  • Ocgsk.Text_node A render node drawing a set of glyphs.
  • Ocgsk.Texture_node A render node for a GdkTexture.
  • Ocgsk.Texture_scale_node A render node for a GdkTexture, with control over scaling.
  • Ocgsk.Transform_node A render node applying a GskTransform to its single child node.

Records

  • Ocgsk.Color_stop A color stop in a gradient node.
  • Ocgsk.Component_transfer Specifies a transfer function for a color component to be applied while rendering.
  • Ocgsk.Parse_location A location in a parse buffer.
  • Ocgsk.Path Describes lines and curves that are more complex than simple rectangles.
  • Ocgsk.Path_builder Constructs GskPath objects.
  • Ocgsk.Path_measure Performs measurements on paths such as determining the length of the path.
  • Ocgsk.Path_point Represents a point on a path.
  • Ocgsk.Rounded_rect A rectangular region with rounded corners.
  • Ocgsk.Shader_args_builder Builds the uniforms data for a GskGLShader.
  • Ocgsk.Shadow The shadow parameters in a shadow node.
  • Ocgsk.Stroke Collects the parameters that are needed when stroking a path.
  • Ocgsk.Transform Describes a 3D transform.
