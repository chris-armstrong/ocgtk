Module Generate.Dune_file

val stub_batch_size : int
val order_stub_names_for_batching : string list -> string list

Sort the stub file names so that every namespace's enum converter file (ml_<ns>_enums_gen) lands inside the first batch: the native linker scans the batch archives in the reverse of the order they are listed, so batch_0 is scanned last and its single-archive rescan is what resolves the mutual references between class stubs and their enum converters.

Content of <pkg>/raw/generated/dune.inc, included by the hand-written <pkg>/raw/dune that declares the raw library: the pkg-config rule, the header copies, and the C stubs library oc<ns>_raw_stubs (split into batches when large), which depends on the other namespaces' raw libraries for their headers.

Content of <pkg>/generated/dune: library oc<ns>, depending on its own raw and enums libraries and the other namespaces' main libraries. When core_modules (the hand-written modules in <pkg>/core/) is not empty, it copies them into the library.
