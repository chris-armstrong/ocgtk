Class Static_resource.static_resource

Wraps a layer 1 handle, Ocgio.Raw.Static_resource.t. Apply it directly only to convert a handle obtained from layer 1: constructors, and methods that return a GStaticResource, give one already wrapped.

method fini : unit -> unit

Finalizes a Gio.Resource initialized by Gio.StaticResource.init.

This is normally used by code generated by glib-compile-resources and is not typically used by other code.

method get_resource : unit -> Ocgio.Raw.Resource.t

Gets the Gio.Resource that was registered by a call to Gio.StaticResource.init.

This is normally used by code generated by glib-compile-resources and is not typically used by other code.

method init : unit -> unit

Initializes a Gio.Resource from static data using a Gio.StaticResource.

This is normally used by code generated by glib-compile-resources and is not typically used by other code.
