Class Converter.converter

Wraps a layer 1 handle, Ocgio.Raw.Converter.t. Apply it directly only to convert a handle obtained from layer 1: constructors, and methods that return a GConverter, give one already wrapped.

method convert_bytes : Ocglib.Glib_bytes.t -> (Ocglib.Glib_bytes.t, Ocglib.GError.t) Stdlib.result

Applies converter to the data in bytes.

method reset : unit -> unit

Resets all internal state in the converter, making it behave as if it was just created. If the converter has any internal state that would produce output then that output is lost.
