Module Ocgio.App_launch_context

Integrating the launch with the launching application. This is used to handle for instance startup notification and launching the new application on the same screen as the launching window.

Its methods, signals and properties are on app_launch_context_t. Its constructors are under Constructors. The functions it is built on are in Ocgio.Raw.App_launch_context.
