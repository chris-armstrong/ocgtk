Class File_input_stream.file_input_stream

Wraps a layer 1 handle, Ocgio.Raw.File_input_stream.t. Apply it directly only to convert a handle obtained from layer 1: constructors, and methods that return a GFileInputStream, give one already wrapped.

method query_info : string -> Ocgio.Cancellable.cancellable_t option -> (Ocgio.File_info.file_info_t, Ocglib.GError.t) Stdlib.result

Queries a file input stream the given attributes. This function blocks while querying the stream. For the asynchronous (non-blocking) version of this function, see g_file_input_stream_query_info_async(). While the stream is blocked, the stream will set the pending flag internally, and any other operations on the stream will fail with G_IO_ERROR_PENDING.
