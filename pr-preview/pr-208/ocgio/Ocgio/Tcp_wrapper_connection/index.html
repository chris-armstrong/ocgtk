Module Ocgio.Tcp_wrapper_connection

A GTcpWrapperConnection can be used to wrap a Gio.IOStream that is based on a Gio.Socket, but which is not actually a Gio.SocketConnection. This is used by Gio.SocketClient so that it can always return a Gio.SocketConnection, even when the connection it has actually created is not directly a Gio.SocketConnection.

Its methods, signals and properties are on tcp_wrapper_connection_t. Its constructors are under Constructors. The functions it is built on are in Ocgio.Raw.Tcp_wrapper_connection.
