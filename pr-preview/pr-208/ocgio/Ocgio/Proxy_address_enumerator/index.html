Module Ocgio.Proxy_address_enumerator

GProxyAddressEnumerator is a wrapper around Gio.SocketAddressEnumerator which takes the Gio.SocketAddress instances returned by the Gio.SocketAddressEnumerator and wraps them in Gio.ProxyAddress instances, using the given Gio.ProxyAddressEnumerator:proxy-resolver.

This enumerator will be returned (for example, by Gio.SocketConnectable.enumerate) as appropriate when a proxy is configured; there should be no need to manually wrap a Gio.SocketAddressEnumerator instance with one.

Its methods, signals and properties are on proxy_address_enumerator_t. The functions it is built on are in Ocgio.Raw.Proxy_address_enumerator.
