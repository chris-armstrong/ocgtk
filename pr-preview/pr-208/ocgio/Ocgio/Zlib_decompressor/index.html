Module Ocgio.Zlib_decompressor

GZlibDecompressor is an implementation of Gio.Converter that decompresses data compressed with zlib.

Its methods, signals and properties are on zlib_decompressor_t. Its constructors are under Constructors. The functions it is built on are in Ocgio.Raw.Zlib_decompressor.
