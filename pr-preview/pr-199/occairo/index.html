occairo

The occairo package provides OCaml bindings for the GObject types of Cairo, the 2D vector graphics library: drawing contexts, paths, patterns and surfaces. They are generated from Cairo's GObject introspection data.

  • Modules
  • Dependencies

Modules

The library is reached as Occairo, with one module per class, interface or record, such as Occairo.Context and Occairo.Pattern.

  • Occairo.Enums — enumerations and bitfields.
  • Occairo.Raw — the C externals and abstract types the modules above are built on.

Dependencies

It builds on Ocglib (GLib and GObject).
