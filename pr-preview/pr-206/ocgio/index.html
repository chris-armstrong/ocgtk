ocgio

The ocgio package provides OCaml bindings for GIO: I/O, files, and the application and networking abstractions from GLib's application framework. They are generated from GIO's GObject introspection data.

  • Modules
  • Dependencies

Modules

The library is reached as Ocgio, with one module per class, interface or record, such as Ocgio.File and Ocgio.Application.

  • Ocgio.Enums — enumerations and bitfields.
  • Ocgio.Constants — constants.
  • Ocgio.Raw — the C externals and abstract types the modules above are built on.

Dependencies

It builds on Ocglib (GLib and GObject).
