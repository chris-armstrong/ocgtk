val attach_null_phrases : Doc_ast.inline list -> Doc_ast.inline list

Folds the prose after a Null into it, at one level: nested inlines are left alone, since the parser applies it to each inline list it builds. Before "-terminated" or " terminated" the literal becomes the plain word "null"; before an error phrase (" on error", " if an error occurred", ...) it becomes Null_on_error phrase, and the phrase leaves the following text.

val strip_ownership : Doc_ast.block list -> Doc_ast.block list * Doc_ast.fallback list

Drops each sentence of a paragraph or list item that tells the caller to free a value (the ownership allowlist: "free(d) … with g_…", "use g_…free" or "use g_…unref", "unref(fed) … with"), one Ownership_stripped event per sentence naming the pattern. A sentence that only mentions a free function is kept. A paragraph or item left empty is removed, and a list left empty too. Code blocks and headings are never touched. A block with no matching sentence is returned unchanged.
