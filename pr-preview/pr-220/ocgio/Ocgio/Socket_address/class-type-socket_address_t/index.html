Class type Socket_address.socket_address_t

The methods, signals and properties of a SocketAddress.

Implements:

  • Ocgio.Socket_connectable

GSocketAddress is the equivalent of struct sockaddr) and its subtypes in the BSD sockets API. This is an abstract class; use Gio.InetSocketAddress for internet sockets, or Gio.UnixSocketAddress for UNIX domain sockets.
