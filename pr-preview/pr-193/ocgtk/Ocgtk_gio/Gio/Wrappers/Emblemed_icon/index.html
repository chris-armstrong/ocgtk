Module Wrappers.Emblemed_icon

GEmblemedIcon is an implementation of Gio.Icon that supports adding an emblem to an icon. Adding multiple emblems to an icon is ensured via Gio.EmblemedIcon.add_emblem.

Note that GEmblemedIcon allows no control over the position of the emblems. See also Gio.Emblem for more information.
