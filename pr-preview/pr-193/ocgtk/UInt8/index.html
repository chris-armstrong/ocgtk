Module UInt8

Unsigned 8-bit integer (guint8).

Backed by private int — no heap allocation. Range: 0, 255.

type t = private int
val of_int : int -> t

of_int n converts n to a UInt8.t. Raises Invalid_argument if n < 0 || n > 255.

val to_int : t -> int

to_int v returns the underlying integer value.

val min_int : t

The minimum value: 0.

val max_int : t

The maximum value: 255.

val zero : t

Alias for min_int: 0.

val min_value : int

The minimum value representable as an int, equal to to_int min_int.

val max_value : int

The maximum value representable as an int, equal to to_int max_int.
