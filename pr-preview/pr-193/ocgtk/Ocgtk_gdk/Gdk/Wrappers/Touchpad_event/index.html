Module Wrappers.Touchpad_event

An event related to a gesture on a touchpad device.

Unlike touchscreens, where the windowing system sends basic sequences of begin, update, end events, and leaves gesture recognition to the clients, touchpad gestures are typically processed by the system, resulting in these events.

type t = [ `touchpad_event | `event ] Gobject.obj
val get_pinch_scale : t -> float

Extracts the scale from a touchpad pinch event.

val get_pinch_angle_delta : t -> float

Extracts the angle delta from a touchpad pinch event.

val get_n_fingers : t -> int

Extracts the number of fingers from a touchpad event.

val get_gesture_phase : t -> Gdk_enums.touchpadgesturephase

Extracts the touchpad gesture phase from a touchpad event.

val get_deltas : t -> float * float

Extracts delta information from a touchpad event.
