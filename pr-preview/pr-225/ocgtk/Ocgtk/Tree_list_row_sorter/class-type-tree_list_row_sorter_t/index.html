Class type Tree_list_row_sorter.tree_list_row_sorter_t

The methods, signals and properties of a TreeListRowSorter.

Inherits from: Ocgtk.Sorter

Applies a gives sorter to the levels in a tree.

Here is an example for setting up a column view with a tree model and a GtkTreeListSorter:

column_sorter = gtk_column_view_get_sorter view;
sorter = gtk_tree_list_row_sorter_new (g_object_ref column_sorter);
sort_model = gtk_sort_list_model_new (tree_model, sorter);
selection = gtk_single_selection_new sort_model;
gtk_column_view_set_model (view, G_LIST_MODEL selection)
