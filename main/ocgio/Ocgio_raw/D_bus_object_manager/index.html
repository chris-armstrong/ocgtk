Module Ocgio_raw.D_bus_object_manager

The GDBusObjectManager type is the base type for service- and client-side implementations of the standardized org.freedesktop.DBus.ObjectManager interface.

See Gio.DBusObjectManagerClient for the client-side implementation and Gio.DBusObjectManagerServer for the service-side implementation.
