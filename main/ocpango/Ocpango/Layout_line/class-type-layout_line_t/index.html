Class type Layout_line.layout_line_t

The methods, signals and properties of a LayoutLine.

A PangoLayoutLine represents one of the lines resulting from laying out a paragraph via PangoLayout.

PangoLayoutLine structures are obtained by calling Pango.Layout.get_line and are only valid until the text, attributes, or settings of the parent PangoLayout are modified.
